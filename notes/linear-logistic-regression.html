Linear and logistic regression

The two models every other model gets compared with, worked down to the last step: least squares by hand and as a projection, what each assumption protects and what breaks without it, standard errors and what a coefficient really says, ridge and lasso, the bias–variance decomposition, and logistic regression from log-odds to Newton's method, separation and rare events.

About 60 minutes, plus 32 questions · two tiny datasets worked by hand (five salaries, six students)

In short

  1. Ordinary least squares (OLS) picks the line with the smallest sum of squared misses. Setting the gradient to zero gives the normal equations \(X^\top X\hat\beta = X^\top y\). Geometrically, OLS drops a perpendicular from \(y\) onto the space of all possible predictions, so the residuals are at right angles to every feature column, and with an intercept they sum to zero. Five salaries give \(\hat y = 1.8 + 1.2 \times \text{years}\).
  2. Each assumption protects something different. Unbiased coefficients need nothing important left out that moves with the features (exogeneity). Valid standard errors also need independent rows and constant noise variance, or else robust or clustered standard errors. Normal errors only make small-sample tests exact. Most failures break the standard errors; omitted variables break the coefficients themselves.
  3. A coefficient is the change in the prediction per unit of one feature with the others held fixed. Its standard error \(\hat\sigma\sqrt{[(X^\top X)^{-1}]_{jj}}\) shrinks with more rows, less noise and more spread in the feature, and grows with collinearity by \(\sqrt{\text{VIF}}\). It's an association; it's causal only when nothing is confounding it.
  4. Ridge adds \(\lambda\) to every curvature of the loss bowl: it shrinks the poorly determined directions most, never to exactly zero, and splits weight between correlated features. Lasso's pull towards zero has constant strength, so weak coefficients land exactly on zero (the soft threshold); it tends to keep one of a correlated pair. Standardize first; choose \(\lambda\) by cross-validation.
  5. Expected squared test error = noise + bias² + variance. Flexibility trades bias for variance, regularization trades variance for bias, and more data cuts variance for free. For one ridge coefficient the best penalty is exactly \(\sigma^2/\beta^2\): shrink hardest when the signal is weak.
  6. Logistic regression is a linear model for the log-odds. Log loss is the Bernoulli negative log-likelihood, its gradient is \(X^\top(p - y)\), and it's convex but has no closed form, so Newton's method (IRLS) finishes in a handful of steps. \(e^{\beta}\) is an odds ratio. Perfect separation sends the weights to infinity, which a penalty fixes; keeping only a fraction \(q\) of the negatives raises only the intercept, by \(\log(1/q)\).

01Least squares, by hand and as a projection

Linear regression predicts a number as a constant plus a weighted sum of the features. Stack the \(n\) rows into a matrix \(X\) whose first column is all ones (that column carries the constant, the intercept), and the model for every row at once is:

\[ \begin{aligned} y_i &= \beta_0 + \beta_1 x_{i1} + \dots + \beta_p x_{ip} + \varepsilon_i \\ y &= X\beta + \varepsilon \end{aligned} \]

In words: \(X\) is \(n \times k\) with \(k = p + 1\) columns, \(\beta\) holds one weight per column, and \(\varepsilon\) (the noise or error) is everything about \(y\) that the features don't explain. The prediction drops the noise: \(\hat y = X\hat\beta\).

“Linear” means linear in the weights, not in the inputs. Adding \(x^2\), \(\log x\) or \(x_1 x_2\) as extra columns is still linear regression, because the prediction is still a weighted sum of columns. What can't be written this way is a weight inside a function, like \(e^{\beta x}\) or a threshold learned from the data.

OLS by hand

For a candidate line, each person's residual is the miss \(e_i = y_i - \hat y_i\). Ordinary least squares (OLS) picks the line with the smallest residual sum of squares, \(\text{RSS} = \sum_i e_i^2\). Squaring counts misses in either direction, punishes big misses most, makes the loss smooth enough to solve exactly, and makes the best prediction the conditional mean of \(y\). Under Gaussian noise it is also the maximum-likelihood fit (loss functions derives that).

First, the intercept. For any slope \(b\), the best intercept makes the residuals average zero (its derivative is \(-2\sum_i e_i\)), which puts the line through the point of means \((\bar x, \bar y) = (3, 5.4)\). That leaves one number to choose. Write \(S_{xx} = \sum_i (x_i - \bar x)^2\), \(S_{xy} = \sum_i (x_i - \bar x)(y_i - \bar y)\) and \(S_{yy} = \sum_i (y_i - \bar y)^2\):

The normal equations, derived

With several features the same idea needs matrices. The steps, each one short:

  1. Write the loss. \(L(\beta) = \lVert y - X\beta \rVert^2 = (y - X\beta)^\top (y - X\beta)\), the RSS as a dot product.
  2. Expand. \(L = y^\top y - 2\beta^\top X^\top y + \beta^\top X^\top X\beta\). The two cross terms are equal scalars, so they combine.
  3. Differentiate. \(\nabla_\beta(a^\top\beta) = a\), and \(\nabla_\beta(\beta^\top A\beta) = 2A\beta\) for a symmetric \(A\) such as \(X^\top X\). So \(\nabla L = -2X^\top y + 2X^\top X\beta = -2X^\top(y - X\beta)\).
  4. Set it to zero and divide by \(-2\): \(X^\top(y - X\hat\beta) = 0\).
  5. Rearrange: \(X^\top X\hat\beta = X^\top y\), the normal equations. If \(X^\top X\) can be inverted, \(\hat\beta = (X^\top X)^{-1}X^\top y\).
  6. Check it's a minimum. The second derivative (the Hessian) is \(2X^\top X\), and for any direction \(v\), \(v^\top X^\top X v = \lVert Xv \rVert^2 \ge 0\). The loss is a bowl that never curves down (convex), so the flat point is the global bottom. It's the only bottom when no column is a weighted sum of the others (full column rank).
\[ \begin{aligned} \nabla L &= -2X^\top (y - X\beta) \\ X^\top X\hat\beta &= X^\top y \\ \hat\beta &= (X^\top X)^{-1}X^\top y \end{aligned} \]

In words: entry \(j\) of the gradient is feature column \(j\) dotted with the residuals. At the bottom every one of those dot products is zero: no feature lines up with what's left over. If one did, moving its weight would lower the loss.

By hand on the five salaries. With columns (ones, years), \(X^\top X\) holds \(n, \sum x, \sum x^2\) and \(X^\top y\) holds \(\sum y, \sum xy\):

\[ \begin{aligned} X^\top X &= \begin{bmatrix} 5 & 15 \\ 15 & 55 \end{bmatrix}, \quad X^\top y = \begin{bmatrix} 27 \\ 93 \end{bmatrix} \\ (X^\top X)^{-1} &= \frac{1}{5 \cdot 55 - 15^2}\begin{bmatrix} 55 & -15 \\ -15 & 5 \end{bmatrix} = \frac{1}{50}\begin{bmatrix} 55 & -15 \\ -15 & 5 \end{bmatrix} \\ \hat\beta &= \frac{1}{50}\begin{bmatrix} 55 \cdot 27 - 15 \cdot 93 \\ -15 \cdot 27 + 5 \cdot 93 \end{bmatrix} = \frac{1}{50}\begin{bmatrix} 90 \\ 60 \end{bmatrix} = \begin{bmatrix} 1.8 \\ 1.2 \end{bmatrix} \end{aligned} \]

In words: a 2×2 inverse swaps the diagonal, negates the off-diagonal and divides by the determinant. Same line as before.

When \(X^\top X\) can't be inverted (it's singular): some column is an exact combination of others. A duplicated column, the same quantity in two units, all one-hot dummies plus an intercept (the dummy trap), or more features than rows (\(p \ge n\)). Then infinitely many \(\beta\) give the same, equally good predictions; only the coefficients are undetermined. np.linalg.lstsq returns the one with the smallest length (the minimum-norm solution), and ridge (section 04) makes the answer unique again.

Trap

“Compute \((X^\top X)^{-1}\) and multiply.” Never in code: solving the system (np.linalg.solve) is cheaper and more accurate than inverting, and lstsq (SVD) or QR are safer still, because they work on \(X\) directly and never form \(X^\top X\). Forming it squares the condition number (the ratio of the matrix's largest to smallest stretch, which sets how much rounding error gets amplified; section below).

The geometric view: a projection

Stop thinking of five points on a plot. Think of the five salaries as one point \(y\) in five-dimensional space, one axis per person. Every choice of \(\beta\) gives another point \(X\beta\), and all of them together form a flat surface through the origin: the set of all weighted sums of the columns, called the column space of \(X\). Here it's a 2-D plane inside 5-D space, spanned by the ones column and the years column.

OLS picks the point on that plane closest to \(y\). The closest point is found by dropping a perpendicular, like a plumb line: the orthogonal projection.

\[ \begin{aligned} \hat y &= X\hat\beta = X(X^\top X)^{-1}X^\top y = Hy \\ H &= X(X^\top X)^{-1}X^\top, \quad H^2 = H \\ X^\top e &= X^\top (y - \hat y) = 0 \end{aligned} \]

In words: the hat matrix \(H\) “puts the hat on \(y\)”. Applying it twice changes nothing (\(H^2 = H\)), because a point already on the plane projects to itself. The residual is perpendicular to every column, which is exactly the normal equations again.

Check on the example. With residuals \((0, 0.8, -1.4, 0.4, 0.2)\): against the ones column, \(\sum_i e_i = 0\); against the years column, \(\sum_i x_i e_i = 0 + 1.6 - 4.2 + 1.6 + 1.0 = 0\). Everything below follows from this right angle:

  • With an intercept, residuals sum to zero, so the average prediction equals \(\bar y\) and the line passes through the point of means.
  • Pythagoras splits the variation. \(e\) is also perpendicular to \(\hat y - \bar y\), so the total sum of squares \(\text{TSS} = \sum_i (y_i - \bar y)^2\) splits into explained (\(\text{ESS}\)) and residual parts: \(17.2 = 14.4 + 2.8\). That split is why in-sample \(R^2\) with an intercept lies between 0 and 1 (section 03).
  • Leverage. The diagonal entry \(h_{ii}\) of \(H\) says how strongly row \(i\)'s own \(y\) pulls its own fitted value. With one feature \(h_{ii} = \tfrac1n + (x_i - \bar x)^2/S_{xx}\), so here it's \(0.2 + 4/10 = 0.6\) at the ends and \((0.6, 0.3, 0.2, 0.3, 0.6)\) in all: the end points (1 and 5 years) pull hardest, the middle one least. The leverages sum to \(k = 2\), so they average \(k/n\). Leverage depends only on \(X\).
  • Degrees of freedom. The residual is forced into the \(n - k = 3\) dimensions perpendicular to the plane. That's why the noise variance is estimated by dividing RSS by \(n - k\), not \(n\) (section 03).
  • No distribution was needed. The projection is pure geometry. Probability enters only when asking how much \(\hat\beta\) would move with fresh noise.

Why the intercept and centering matter

Dropping the intercept forces the line through the origin. On the salaries that gives slope \(\sum xy / \sum x^2 = 93/55 = 1.69\) instead of 1.2, and residuals that sum to 1.64 instead of 0. Unless the true line really passes through \((0, 0)\), the slope is biased, and \(R^2\) measured against \(\bar y\) is no longer guaranteed to lie in \([0, 1]\). Keep the intercept unless theory says it must be zero.

Centering means subtracting the mean from each feature, here \(x - \bar x = (-2, -1, 0, 1, 2)\). The fitted line is the same; what changes:

  • The intercept becomes \(\bar y\). \(X^\top X\) turns into \(\operatorname{diag}(5, 10)\): the off-diagonal \(\sum x\) is now zero, so intercept and slope separate. The intercept is 5.4, the salary at average experience, and the slope stays 1.2. Their estimates also become uncorrelated (the raw covariance of −0.28 drops to 0).
  • Interpretation. The raw intercept is the prediction at \(x = 0\). For years of experience that's a fresher, fine. For flat size it's a flat of 0 m²: an extrapolation nobody should read.
  • Conditioning. The curvatures of the loss bowl (for the \(\tfrac{1}{2n}\)-scaled squared error used in the next section) are the eigenvalues of \(X^\top X/n\): 11.83 and 0.169 raw (a ratio, the condition number, of 70), 2 and 1 centred (ratio 2). Gradient descent's speed depends on that ratio (next section).
  • Polynomials and interactions. For positive \(x\), the columns \(x\) and \(x^2\) are almost collinear; centering first removes most of that. With an interaction \(x_1 x_2\), centering makes \(\beta_1\) the effect of \(x_1\) at the average \(x_2\) rather than at \(x_2 = 0\).
  • Penalties. Ridge and lasso must not shrink the intercept, or every prediction gets pulled towards 0. The standard recipe: centre \(X\) and \(y\), fit the penalized slopes, then set \(\hat\beta_0 = \bar y - \bar x^\top\hat\beta\).

Closed form or gradient descent

Gradient descent walks downhill instead of solving in one shot. For the loss \(\frac{1}{2n}\lVert y - X\beta \rVert^2\) (the \(\frac12\) cancels the 2, the \(\frac1n\) averages):

\[ \beta \leftarrow \beta - \eta\,\frac{1}{n}X^\top (X\beta - y) \]

In words: \(X\beta - y\) is each row's miss, \(X^\top\) lines the misses up with each feature, and \(\eta\) (the learning rate) sets the step size.

Say it in an interview: “OLS minimizes the sum of squared residuals. Setting the gradient \(-2X^\top(y - X\beta)\) to zero gives the normal equations \(X^\top X\beta = X^\top y\), unique when \(X\) has full column rank. Geometrically it projects \(y\) onto the column space, so the residuals are orthogonal to every feature and, with an intercept, sum to zero. In code I'd use lstsq or QR, never an explicit inverse, and gradient descent only for huge or streaming data, after scaling.”

02Assumptions: what each one protects

The projection needs no assumptions: it always finds the best-fitting line. The assumptions are about something else: whether the coefficients mean what you want them to mean, and whether their standard errors are honest. Substitute \(y = X\beta + \varepsilon\) into the OLS formula and the whole story is in one line:

\[ \begin{aligned} \hat\beta &= (X^\top X)^{-1}X^\top (X\beta + \varepsilon) \\ &= \beta + (X^\top X)^{-1}X^\top\varepsilon \end{aligned} \]

In words: the estimate is the truth plus a weighted mix of the noise. If the noise averages to zero whatever the features are, the mix averages to zero and \(\hat\beta\) is right on average. How much the mix wobbles depends on the noise's variance and correlations. Each assumption below controls one of those two things.

The assumptions, precisely

  1. Linearity (correct functional form): the average of \(y\) given the features really is \(X\beta\) for some \(\beta\). Curves and interactions have to be in the columns.
  2. Exogeneity: \(E[\varepsilon \mid X] = 0\). Nothing left in the noise moves with the features: no omitted variable that is correlated with a feature and affects \(y\), no feedback from \(y\) to \(x\), no measurement error in \(x\).
  3. Independence: the rows' errors are uncorrelated. Broken by repeated measurements of one user, by time order, by geography.
  4. Constant variance (homoscedasticity): \(\operatorname{Var}(\varepsilon_i \mid X) = \sigma^2\) for every row. Its failure is heteroscedasticity: say, expensive flats are noisier than cheap ones.
  5. Normal errors: \(\varepsilon \sim \mathcal N(0, \sigma^2 I)\). The least important.
  6. No perfect collinearity: no column is an exact combination of others, so \(X^\top X\) is invertible and \(\hat\beta\) is unique.

The Gauss–Markov theorem. Under 1–4 and 6 (no normality needed), OLS is BLUE: the best (lowest-variance) linear unbiased estimator. 1, 2 and 6 give unbiasedness (take the expectation of the line above); 3 and 4 make the noise's covariance \(\sigma^2 I\). With \(A = (X^\top X)^{-1}X^\top\), the rule for a linear map of random noise, \(\operatorname{Var}(A\varepsilon) = A\operatorname{Var}(\varepsilon)A^\top\), gives

\[ \operatorname{Var}(\hat\beta \mid X) = (X^\top X)^{-1}X^\top(\sigma^2 I)X(X^\top X)^{-1} = \sigma^2(X^\top X)^{-1} \]

In words: the coefficient cloud's spread is the noise variance times the inverse of the bowl's shape. The catch is the word unbiased: ridge is biased on purpose and can beat OLS on total error (section 05).

  • For explanation (what does a feature do? is it significant?) exogeneity is the one that matters most, and it's the one the data can't check for you.

Fixes: transforms, robust and clustered standard errors

Transform the target when the noise is multiplicative: prices, incomes, durations. \(\log y\) turns “±10%” noise into constant-variance noise and often straightens curves too (Box–Cox picks the power by likelihood; see data preparation). It changes what the coefficients mean (section 03).

Robust (sandwich) standard errors keep the OLS coefficients and fix only the uncertainty. The general variance has the noise covariance \(\Omega\) in the middle; the classic formula assumes \(\Omega = \sigma^2 I\), and the robust one estimates each row's variance from its own squared residual:

\[ \begin{aligned} \operatorname{Var}(\hat\beta) &= (X^\top X)^{-1}\,X^\top \Omega X\,(X^\top X)^{-1} \\ \widehat{\operatorname{Var}}_{\text{HC0}} &= (X^\top X)^{-1}\Big(\sum_i e_i^2\, x_i x_i^\top\Big)(X^\top X)^{-1} \end{aligned} \]

In words: the two \((X^\top X)^{-1}\) are the bread, the middle is the meat. HC0 puts each row's \(e_i^2\) in the meat. HC1 multiplies by \(n/(n - k)\); HC3 uses \(e_i^2/(1 - h_{ii})^2\), which corrects for high-leverage rows hiding their own noise and is the safer choice in small samples.

When does heteroscedasticity actually break the classic standard error? When the noise variance is large exactly where \((x - \bar x)^2\) is large, since those rows dominate the slope. Simulated with 100 rows, true slope 2, noise spread proportional to \(x\), refitted 4,000 times:

Weighted least squares (WLS) goes further when the variance pattern is known: weight each squared residual by \(1/\sigma_i^2\), so noisy rows count less. That restores the lowest-variance estimator: in the two designs above, weights \(1/x^2\) roughly halve the slope's spread, from about 0.10 to 0.05 (uniform) and from about 0.15 to 0.09 (skewed). Robust SEs fix the honesty of the uncertainty; WLS also shrinks it.

Clustered standard errors. When rows come in groups (orders per customer, students per school, users per city) and the errors within a group are correlated, the effective sample size is closer to the number of groups than the number of rows. The cluster-robust estimator sums \(x_i e_i\) within each cluster before squaring, so correlated errors inside a cluster add up instead of cancelling. For a feature that's constant within clusters of size \(m\), the variance is inflated by about the design effect \(1 + (m - 1)\rho\), with \(\rho\) the within-cluster correlation of the errors.

  • Time series: HAC (Newey–West) standard errors allow correlation between nearby rows. The same logic applies to A/B tests analysed per session when users were randomized (hypothesis testing).

Say it in an interview: “Unbiased coefficients need exogeneity: nothing omitted that's correlated with the features and affects \(y\). Independence and constant variance are about the standard errors: when they fail, the coefficients are still unbiased but the classic SEs are wrong, so I use robust HC3 SEs, cluster at the level of the correlated rows, or model the variance with weights or a log target. Normality only matters for small-sample tests and prediction intervals. I check all of it with residual-vs-fitted, Q–Q and leverage plots.”

03Inference: standard errors, tests and what a coefficient means

The fitted slope 1.2 came from one noisy sample of five people. Collect five new people with the same experience levels and the slope would come out different. Inference asks how different, and whether the slope could plausibly be zero.

Standard errors, by hand

From section 02, \(\operatorname{Var}(\hat\beta) = \sigma^2(X^\top X)^{-1}\). The true noise variance \(\sigma^2\) is unknown, so estimate it from the residuals:

\[ \begin{aligned} \hat\sigma^2 &= \frac{\text{RSS}}{n - k} = \frac{2.8}{5 - 2} = 0.933 \\ \operatorname{SE}(\hat\beta_j) &= \hat\sigma\sqrt{\big[(X^\top X)^{-1}\big]_{jj}} \\ \operatorname{SE}(\hat\beta_1) &= \sqrt{0.933 \times \tfrac{5}{50}} = 0.306, \quad \operatorname{SE}(\hat\beta_0) = \sqrt{0.933 \times \tfrac{55}{50}} = 1.013 \end{aligned} \]

In words: the standard error (SE) is how much the coefficient would typically wobble across repeated samples. The diagonal of \((X^\top X)^{-1}\) is read off the 2×2 inverse from section 01.

  • Why divide by \(n - k\), not \(n\). The line was bent towards these very points using \(k\) numbers, so the residuals come out smaller than the true errors. The residual vector lives in only \(n - k\) dimensions (the projection), and dividing by \(n - k\) makes \(\hat\sigma^2\) unbiased. The maximum-likelihood estimate RSS\(/n\) = 0.56 runs low, for the same reason the sample variance divides by \(n - 1\).
  • With one feature the formula is \(\operatorname{Var}(\hat\beta_1) = \sigma^2/S_{xx}\): \(0.933/10 = 0.0933\), the same. Points spread far apart along \(x\) pin the slope like a long lever; bunched points let it tilt.
  • What makes an SE small: less noise (\(\sigma^2\)), more spread in the feature (\(S_{xx}\)), more rows (\(S_{xx}\) grows with \(n\), so SE falls like \(1/\sqrt n\)), and little overlap with the other features (the VIF, below).

t-statistics and confidence intervals

To test “no effect” for one coefficient, divide the estimate by its SE: how many wobbles from zero it sits. Because \(\hat\sigma\) is estimated, the ratio follows a \(t\) distribution with \(n - k\) degrees of freedom (exactly, under normal errors; approximately otherwise), not a normal. The logic of the test and the p-value is the same as in hypothesis testing.

\[ \begin{aligned} t &= \frac{\hat\beta_1 - 0}{\operatorname{SE}(\hat\beta_1)} = \frac{1.2}{0.306} = 3.93 \\ p &= P(\lvert T_3 \rvert \ge 3.93) = 0.029 \\ \text{CI}_{95} &= \hat\beta_1 \pm t_{3,\,0.975}\operatorname{SE} = 1.2 \pm 3.182 \times 0.306 = [0.23,\ 2.17] \end{aligned} \]

In words: if experience truly had no effect, a slope this many SEs from zero would turn up in about 3% of samples, so it's significant at 5%. The interval is wide, though: anything from 0.23 to 2.17 lakh a year fits the data. With 3 degrees of freedom the critical value is 3.18, not 1.96; by about 30 degrees of freedom it's close to 2.04, and then 1.96.

  • The intercept: \(t = 1.8/1.013 = 1.78\), \(p = 0.17\): five people can't pin down a fresher's salary.
  • The test is conditional on the other features: “no effect of \(x_j\) holding the others fixed”. Drop or add a correlated feature and the question changes.
  • Interval and test agree: the 95% interval excludes 0 exactly when the two-sided test rejects at 5% (duality).
  • With huge data almost every coefficient is “significant”, because the SE shrinks like \(1/\sqrt n\). Read the size and the interval, not the p-value.

The F-test: several coefficients at once

To test whether a group of \(q\) coefficients is zero (all dummies of one category, a feature and its square, two collinear twins), fit the model with and without them and compare how much the RSS rises per dropped coefficient, relative to the noise level:

\[ \begin{aligned} F &= \frac{(\text{RSS}_{\text{restricted}} - \text{RSS}_{\text{full}})/q}{\text{RSS}_{\text{full}}/(n - k)} \\ F_{\text{salary}} &= \frac{(17.2 - 2.8)/1}{2.8/3} = 15.43 \end{aligned} \]

In words: the restricted model here is “intercept only”, whose RSS is the TSS, 17.2. Dropping the slope would add 14.4 of squared error, 15.4 times the noise per degree of freedom; under \(F_{1,3}\) that has \(p = 0.029\). With one coefficient, \(F = t^2\) (\(3.93^2 = 15.43\)) and the tests are identical. With several, the F-test can reject even when no individual t-test does: the typical picture with collinear features (below), where each coefficient alone is uncertain but, given enough rows, the pair together is clearly significant.

\(R^2\) and adjusted \(R^2\)

\[ \begin{aligned} R^2 &= 1 - \frac{\text{RSS}}{\text{TSS}} = 1 - \frac{2.8}{17.2} = 0.837 \\ \bar R^2 &= 1 - (1 - R^2)\frac{n - 1}{n - p - 1} = 1 - 0.163 \times \frac{4}{3} = 0.783 \end{aligned} \]

In words: \(R^2\) is the share of the variation in \(y\) the model explains, compared with always predicting \(\bar y\). In-sample with an intercept it equals \(\operatorname{corr}(y, \hat y)^2\). Adjusted \(R^2\) charges for each of the \(p\) features (not counting the intercept).

  • Training \(R^2\) never falls when a feature is added, even pure noise: the projection onto a bigger space can only get closer to \(y\). Adjusted \(R^2\) rises only if the new feature's \(\lvert t \rvert \gt 1\), a much lower bar than significance. For choosing models, use held-out error.
  • On test data \(R^2\) can be negative: the model's squared error is larger than that of always predicting the test set's own mean. As a metric it belongs with the other regression metrics (evaluation).
  • Low \(R^2\) isn't automatically bad (behavioural targets are noisy but a real effect can still be estimated precisely), and high \(R^2\) doesn't mean the model is right (a curve fitted by a line can have \(R^2 = 0.9\) and systematic residuals).

Choosing which features to keep. Stepwise selection by p-values (add or drop one feature at a time while it's “significant”) is a classic interview trap: it runs many tests, so the surviving p-values and intervals are too optimistic, and with correlated features the chosen set is unstable. In-sample criteria such as AIC and BIC charge per parameter and are better (they're likelihood-based; see likelihood, MLE and MAP), but the direct measurement is held-out error, and lasso does selection and fitting in one step (section 04; other selection methods in data preparation).

Confidence interval vs prediction interval. At a new point \(x_0\), “the average salary of people with \(x_0\) years” and “this one person's salary” are different questions:

\[ \begin{aligned} \operatorname{Var}(\text{mean at } x_0) &= \sigma^2\, x_0^\top (X^\top X)^{-1}x_0 = \sigma^2\Big(\frac1n + \frac{(x_0 - \bar x)^2}{S_{xx}}\Big) \\ \operatorname{Var}(\text{new } y \text{ at } x_0) &= \sigma^2\Big(1 + x_0^\top (X^\top X)^{-1}x_0\Big) \end{aligned} \]

In words: the mean's uncertainty comes only from the wobbling line and grows as \(x_0\) moves away from \(\bar x\). A new person adds their own noise, the “1”, which no amount of data removes. At 3 years the prediction is 5.4 with a 95% CI of ±1.37 and a prediction interval of ±3.37; at 6 years (outside the data) it's 9.0, CI [5.78, 12.22], PI [4.54, 13.46].

Multicollinearity: what it does to the variance

When features overlap, only the part of \(x_j\) that the other features can't predict helps pin down \(\beta_j\). So the one-feature variance \(\sigma^2/\sum_i (x_{ij} - \bar x_j)^2\) gets multiplied by the variance inflation factor \(\text{VIF}_j = 1/(1 - R_j^2)\), where \(R_j^2\) is how well the other features predict \(x_j\) (the formula, VIF and condition-number detection, and the remedies are in data preparation). The SE widens by \(\sqrt{\text{VIF}}\): \(R_j^2 = 0.5, 0.8, 0.9, 0.99\) give VIF 2, 5, 10, 100 and SEs 1.4, 2.2, 3.2 and 10 times wider.

Omitted-variable bias

Suppose the truth involves two features but you regress on only one. Write the left-out \(x_2\) as whatever \(x_1\) predicts of it plus a leftover \(u\) that is uncorrelated with \(x_1\), and substitute:

\[ \begin{aligned} y &= \beta_0 + \beta_1 x_1 + \beta_2 x_2 + \varepsilon \\ x_2 &= \delta_0 + \delta x_1 + u \\ y &= (\beta_0 + \beta_2\delta_0) + (\beta_1 + \beta_2\delta)\,x_1 + (\beta_2 u + \varepsilon) \\ E[\tilde\beta_1] &= \beta_1 + \beta_2\,\delta \end{aligned} \]

In words: the short regression's slope \(\tilde\beta_1\) picks up the real effect of \(x_1\) plus the effect of \(x_2\) times how much \(x_2\) tags along with \(x_1\) (\(\delta\), the slope of \(x_2\) on \(x_1\)). The new error term is uncorrelated with \(x_1\), so this is exactly what the short regression estimates.

  • Sign of the bias = sign(\(\beta_2\)) × sign(correlation of \(x_1\) and \(x_2\)). No bias if \(\beta_2 = 0\) (the left-out variable doesn't matter) or \(\delta = 0\) (it's uncorrelated with \(x_1\)).
  • More data doesn't shrink it. The short regression converges, precisely, to the wrong number.

Correlation vs causation

A regression coefficient is a conditional association. It equals the causal effect of \(x_j\) only if exogeneity holds for \(x_j\): conditional on the included features, nothing else that drives \(y\) moves with \(x_j\). That fails when there's

  • an omitted confounder (ability, above);
  • reverse causality (police numbers and crime, ad spend and sales: \(y\) drives \(x\));
  • sample selection (only approved loans have a repayment label, and approval depended on signals that also predict repayment);
  • a bad control: adjusting for a mediator (the path through which \(x\) acts) removes part of the effect you want, and adjusting for a collider (a common consequence of \(x\) and \(y\)) creates a fake association;
  • measurement error in \(x\), which attenuates the slope towards zero.

The fixes are design, not more rows: randomize (A/B tests), or use a quasi-experiment such as difference-in-differences, regression discontinuity or matching (when you can't A/B test), or an instrumental variable (something that moves \(x\) but affects \(y\) only through \(x\)), or fixed effects (a dummy per person or store, which removes every confounder that is constant within it). For pure prediction none of this matters: a confounded feature still predicts, as long as the confounding pattern holds where the model is used.

Say it in an interview: “The SE is \(\hat\sigma\sqrt{[(X^\top X)^{-1}]_{jj}}\) with \(\hat\sigma^2 = \text{RSS}/(n-k)\); \(t = \hat\beta/\text{SE}\) on \(n - k\) degrees of freedom, and an F-test for groups of coefficients. A coefficient is the change in \(y\) per unit of \(x_j\) holding the others fixed; collinearity inflates its variance by the VIF without hurting predictions; leaving out a correlated driver biases it by \(\beta_2\delta\), and more data won't fix that. It's causal only if nothing confounds it, which the regression itself can't check.”

04Regularization: ridge, lasso, elastic net

OLS is unbiased, but with correlated features or many features per row its coefficients wobble wildly (the twins above: spread 5.2 for a true effect of about 1.2). Regularization adds a penalty on the size of the weights, accepting a little bias for a large cut in variance. The intercept is never penalized: centre \(X\) and \(y\) (or leave the ones column out of the penalty), fit the slopes, then recover \(\hat\beta_0 = \bar y - \bar x^\top\hat\beta\).

Ridge: add λ to every curvature

\[ \begin{aligned} L(\beta) &= \lVert y - X\beta \rVert^2 + \lambda\lVert\beta\rVert_2^2 \\ \nabla L &= -2X^\top (y - X\beta) + 2\lambda\beta = 0 \\ \hat\beta_{\text{ridge}} &= (X^\top X + \lambda I)^{-1}X^\top y \end{aligned} \]

In words: the penalty \(\lambda\sum_j\beta_j^2\) is itself a round bowl centred at zero. Adding it adds \(\lambda\) to the diagonal of \(X^\top X\), that is, \(\lambda\) of extra curvature in every direction. \(\lambda = 0\) is OLS; \(\lambda \to \infty\) sends every slope to zero and predicts \(\bar y\).

Always solvable. For any direction \(v \ne 0\), \(v^\top(X^\top X + \lambda I)v = \lVert Xv \rVert^2 + \lambda\lVert v \rVert^2 \gt 0\), so the matrix is invertible even with duplicated columns or \(p \gt n\). That was the original motivation (Hoerl and Kennard, 1970). When \(p \gg n\) the same answer can be computed as \(X^\top(XX^\top + \lambda I)^{-1}y\), an \(n \times n\) solve instead of \(p \times p\); swapping \(XX^\top\) for a matrix of kernel similarities turns this into kernel ridge regression.

One feature, by hand. With centred data the formula becomes \(\hat\beta = S_{xy}/(S_{xx} + \lambda) = 12/(10 + \lambda)\) on the salaries:

Shrinkage along principal directions. With several correlated features, rotate to the axes along which the centred data cloud is long or thin: the eigenvectors \(v_j\) of \(X^\top X\), whose eigenvalues \(d_j^2\) are the squared spreads along them. Along a long axis the data pins the coefficients down well; along a thin one it barely does, which is exactly where OLS wobbles. Ridge keeps a fixed fraction of OLS along each axis:

\[ \begin{aligned} v_j^\top\hat\beta_{\text{ridge}} &= \frac{d_j^2}{d_j^2 + \lambda}\; v_j^\top\hat\beta_{\text{OLS}} \\ X\hat\beta_{\text{ridge}} &= \sum_j u_j\, \frac{d_j^2}{d_j^2 + \lambda}\, u_j^\top y, \quad u_j = Xv_j/d_j \end{aligned} \]

In words: the coefficient vector's component along axis \(j\) is OLS's component times \(d_j^2/(d_j^2 + \lambda)\). That's almost 1 for a long axis (\(d_j^2 \gg \lambda\)) and almost 0 for a thin one (\(d_j^2 \ll \lambda\)). The second line says the same for the predictions: \(u_j\) is axis \(j\) seen in the \(n\)-dimensional space of rows (the singular value decomposition, SVD, \(X = UDV^\top\) packs the \(u_j\), \(d_j\) and \(v_j\) together). The sum of the fractions is the effective degrees of freedom: the number of slopes for OLS, falling to 0 as \(\lambda\) grows.

Worked: the experience twins from section 03. The centred cloud is long along “both columns up together” (\(d^2 = 19.6\)) and razor-thin along “one up, the other down” (\(d^2 = 0.018\)). With \(\lambda = 1\):

  • the long axis keeps \(19.6/20.6 = 95\%\): its component of the coefficient vector goes from 0.854 (OLS) to 0.813;
  • the thin axis keeps \(0.018/1.018 = 1.8\%\): its component, the wild 3.17 that produced 2.83 vs −1.67, drops to 0.057;
  • back in the original coordinates the coefficients are 0.62 and 0.53 (both positive, sum 1.15); with \(\lambda = 10\), 0.41 and 0.39. The effective degrees of freedom at \(\lambda = 1\) are \(0.95 + 0.02 = 0.97\), down from 2.

With an exact duplicate column, ridge gives each copy \(12/(20 + \lambda)\): 0.571 each at \(\lambda = 1\). Splitting a total \(w\) as \(w/2 + w/2\) minimizes \(a^2 + b^2\) subject to \(a + b = w\), so ridge always shares equally between identical columns.

Trap

“Ridge removes useless features.” It never sets a coefficient to exactly zero: the factor \(d_j^2/(d_j^2 + \lambda)\) is positive for every finite \(\lambda\). Ridge shrinks; only an L1 penalty selects.

Lasso: why some coefficients land exactly on zero

\[ L(\beta) = \tfrac12\lVert y - X\beta \rVert^2 + \lambda\lVert\beta\rVert_1 = \tfrac12\lVert y - X\beta \rVert^2 + \lambda\sum_j \lvert\beta_j\rvert \]

In words: the same fit term, with the sum of absolute values as the penalty. (Conventions differ: ridge above uses the full RSS, lasso here half of it, as glmnet does; this makes the one-feature formulas clean, and the comparisons below are about shapes, not equal penalty strengths.) Three ways to see why it produces exact zeros.

1. The push towards zero. The slope of ridge's penalty is \(2\lambda\beta_j\): it fades as \(\beta_j\) shrinks, so it never quite gets there. The slope of \(\lambda\lvert\beta_j\rvert\) is \(\pm\lambda\), the same size however small \(\beta_j\) is. The data's pull on \(\beta_j\) at zero is \(x_j^\top r\), the feature's alignment with the current residual. If that pull is weaker than \(\lambda\), \(\lvert x_j^\top r \rvert \le \lambda\), the coefficient stays at exactly zero (the formal statement uses the subgradient of \(\lvert\cdot\rvert\), which is any value in \([-1, 1]\) at 0).

2. The one-feature solution is a soft threshold. For \(\beta \gt 0\) the derivative is \(-(S_{xy} - \beta S_{xx}) + \lambda\), zero at \(\beta = (S_{xy} - \lambda)/S_{xx}\), which is only valid if \(S_{xy} \gt \lambda\); the negative side mirrors it; otherwise the minimum sits at the kink, \(\beta = 0\):

\[ \begin{aligned} \hat\beta_{\text{lasso}} &= \frac{S(S_{xy},\ \lambda)}{S_{xx}} \\ S(z, \lambda) &= \operatorname{sign}(z)\,\max(\lvert z \rvert - \lambda,\ 0) \end{aligned} \]

In words: the soft-threshold \(S\) moves \(z\) towards zero by \(\lambda\), and anything within \(\lambda\) of zero becomes exactly zero. On the salaries (\(S_{xy} = 12\), \(S_{xx} = 10\)), next to ridge's \(12/(10 + \lambda)\):

Elastic net, and correlated features

How does each penalty split credit between near-copies?

  • Ridge shares: \(a^2 + b^2\) is smallest at an equal split.
  • Lasso doesn't care: for same-sign weights \(\lvert a \rvert + \lvert b \rvert = \lvert a + b \rvert\), so every split costs the same penalty, and the solver typically puts everything on one copy. With the exact duplicate of years at \(\lambda = 1\), lasso gives (1.1, 0) and ridge (0.57, 0.57).
  • Elastic net mixes the two: \(\lambda\big(\alpha\lVert\beta\rVert_1 + \tfrac{1 - \alpha}{2}\lVert\beta\rVert_2^2\big)\). The L1 part still zeroes useless features; the L2 part makes correlated ones enter together with similar weights (the grouping effect), and lets it keep more than \(n\) features. On the duplicate (\(\lambda = 1\), \(\alpha = 0.5\)): (0.56, 0.56).

OLS doesn't care about units: rescale a feature by 12 and its coefficient divides by 12, predictions unchanged. A penalty does care, because it charges the coefficient's size, and the size depends on the units. Experience in months instead of years:

The MAP view in two sentences

With Gaussian noise of variance \(\sigma^2\), putting a Gaussian prior \(\beta_j \sim \mathcal N(0, \tau^2)\) on each weight and taking the most probable weights given the data (the MAP estimate) gives exactly ridge with \(\lambda = \sigma^2/\tau^2\): a tighter prior is a bigger penalty. A Laplace prior, sharply peaked at zero, gives lasso; the derivation and the wider picture are in likelihood, MLE and MAP.

Say it in an interview: “Ridge adds \(\lambda\) to every eigenvalue of \(X^\top X\), so the solution \((X^\top X + \lambda I)^{-1}X^\top y\) always exists; it shrinks each principal direction by \(d^2/(d^2 + \lambda)\), crushing the poorly determined ones that collinearity creates, and never reaches zero. Lasso's penalty pushes with constant force \(\lambda\), so any coefficient whose pull \(\lvert x_j^\top r \rvert\) is below \(\lambda\) sits at exactly zero; the one-feature solution is the soft threshold, and coordinate descent repeats it. Ridge shares weight between correlated features, lasso picks one, elastic net keeps the group. I standardize first, inside the CV pipeline, and pick \(\lambda\) on a log grid by CV, often with the one-SE rule.”

05Bias and variance

Regularization kept promising “a little bias for a lot less variance”. This section makes that exact: the expected test error of any model under squared loss splits into three parts that can be computed separately.

The decomposition, derived

Setup. Data come from \(y = f(x) + \varepsilon\) with \(E[\varepsilon] = 0\) and \(\operatorname{Var}(\varepsilon) = \sigma^2\). A training set \(D\) is drawn and a model \(\hat f_D\) fitted on it. Fix a test point \(x\); its test label has fresh noise, independent of \(D\). Write \(\bar f(x) = E_D[\hat f_D(x)]\) for the average prediction over all the training sets you could have drawn.

  1. Add and subtract \(f\) and \(\bar f\): \(y - \hat f_D = (y - f) + (f - \bar f) + (\bar f - \hat f_D)\). The three pieces are the noise \(\varepsilon\), the bias, and this training set's fluctuation.
  2. Square and take the expectation over training sets and test noise. Three squares and three cross terms.
  3. The cross terms vanish. \(E[\varepsilon(f - \bar f)] = 0\) because \(f - \bar f\) is a fixed number and \(E[\varepsilon] = 0\). \(E[\varepsilon(\bar f - \hat f_D)] = E[\varepsilon]\,E[\bar f - \hat f_D] = 0\) because the test noise is independent of \(D\). \(E[(f - \bar f)(\bar f - \hat f_D)] = (f - \bar f)\,E_D[\bar f - \hat f_D] = 0\) by the definition of \(\bar f\).
  4. What's left is three squares:
\[ \begin{aligned} E\big[(y - \hat f_D(x))^2\big] &= \sigma^2 + \big(f(x) - \bar f(x)\big)^2 + E_D\big[(\hat f_D(x) - \bar f(x))^2\big] \\ &= \text{noise} + \text{bias}^2 + \text{variance} \end{aligned} \]

In words: noise is the floor no model can beat. Bias is how far the average model is from the truth: a model too stiff to bend the right way is wrong the same way every time. Variance is how much the model changes from one training set to another: a flexible model bends to each sample's noise. Average over test points for the overall error.

  • Only squared error splits this cleanly. For 0–1 loss or log loss there are decompositions, but the parts don't simply add.
  • It's a statement about a procedure over many training sets. One fitted model doesn't “have” a variance you can read off; you estimate it by refitting (bootstrap, CV) or by simulation, as below.

Exact numbers: ridge on the five salaries

Take the salary design (\(S_{xx} = 10\)) and suppose the truth is a slope \(\beta = 1.2\) with noise variance \(\sigma^2 = 1\). The ridge slope is \(\hat\beta_\lambda = x_c^\top y/(S_{xx} + \lambda)\), linear in the noise, so its mean and variance can be written down:

\[ \begin{aligned} E[\hat\beta_\lambda] &= \frac{S_{xx}}{S_{xx} + \lambda}\,\beta, \qquad \text{bias} = -\frac{\lambda}{S_{xx} + \lambda}\,\beta \\ \operatorname{Var}(\hat\beta_\lambda) &= \frac{\sigma^2 S_{xx}}{(S_{xx} + \lambda)^2} \\ \text{MSE}(\lambda) &= \frac{\beta^2\lambda^2 + \sigma^2 S_{xx}}{(S_{xx} + \lambda)^2} \end{aligned} \]

In words: \(\lambda\) pulls the average estimate towards zero by the factor \(S_{xx}/(S_{xx} + \lambda)\) (bias), and the same factor squared shrinks the variance.

06Logistic regression

Now the target is yes/no: default or repay, churn or stay, pass or fail. Logistic regression keeps the linear score \(z = x^\top\beta\) and changes two things: the score is turned into a probability, and the loss becomes the negative log-likelihood of coin flips.

The running example: six students

Student123456
Hours studied \(x\)123456
Passed \(y\)001011

Student 3 passed on 3 hours and student 4 failed on 4: no threshold on hours separates the classes perfectly, so a finite best fit exists (section 07 shows what happens when one does).

Why not linear regression on 0/1?

You can run OLS on the labels; it's called the linear probability model. On the six students it gives \(\hat p = -0.2 + 0.2x\). Three problems:

  • It leaves \([0, 1]\). It predicts −0.1 at half an hour and 1.4 at 8 hours. A straight line has no reason to stop at the edges.
  • The effect is forced to be constant. +0.2 per hour whether a student is hopeless or nearly certain, while real probabilities flatten near 0 and 1.
  • The noise breaks OLS's assumptions. A 0/1 outcome has variance \(p(1 - p)\), which changes with \(x\) (heteroscedastic by construction), and isn't remotely normal.

Fitting a sigmoid with squared error instead fixes the range but not the training: its gradient vanishes when the model is confidently wrong and the loss isn't convex (why not MSE).

Log-odds and the sigmoid

The odds are \(p/(1 - p)\): a 20% chance is odds of 0.25 (“1 to 4”), 50% is odds of 1. Odds run from 0 to ∞, and their log, the log-odds or logit, runs over the whole real line, just like a linear score. So model the log-odds linearly and invert:

\[ \begin{aligned} \log\frac{p}{1 - p} &= x^\top\beta = z \\ p &= \sigma(z) = \frac{1}{1 + e^{-z}} \\ \sigma'(z) &= p(1 - p) \end{aligned} \]

In words: the sigmoid \(\sigma\) is the inverse of the logit. It maps \(z = -2, -1, 0, 1, 2\) to 0.119, 0.269, 0.5, 0.731, 0.881. Its slope \(p(1 - p)\) is 0.25 at the middle and near zero at the ends, and it's symmetric: \(\sigma(-z) = 1 - \sigma(z)\).

Why it's still a linear model: the log-odds are linear in \(\beta\), and the decision boundary is flat (section below). It's a generalized linear model: a linear score, a link function (the logit), and a Bernoulli outcome (section 07).

Log loss and its gradient

Each label is a coin flip with chance \(p_i\), so the probability the model gives to what actually happened is \(p_i\) if \(y_i = 1\) and \(1 - p_i\) if \(y_i = 0\). Multiply across rows for the likelihood, take minus the log, and you get log loss (binary cross-entropy). Written on the score \(z\), it simplifies to a form you compute stably with np.logaddexp(0, z); the step-by-step derivation, and why it's the right loss, are in loss functions:

\[ \begin{aligned} J(\beta) &= -\sum_i \big[y_i\log p_i + (1 - y_i)\log(1 - p_i)\big] \\ &= \sum_i \big[\log(1 + e^{z_i}) - y_i z_i\big] \\ \frac{\partial J}{\partial z_i} &= \sigma(z_i) - y_i = p_i - y_i \\ \nabla_\beta J &= X^\top (p - y) \end{aligned} \]

In words: the derivative of \(\log(1 + e^z)\) is \(\sigma(z)\) and of \(yz\) is \(y\), so each row's gradient in its own score is just its miss \(p_i - y_i\); the chain rule through \(z_i = x_i^\top\beta\) multiplies by \(x_i\). The same shape as linear regression's \(X^\top(\hat y - y)\): features times (prediction − target). The sigmoid's own slope \(p(1 - p)\) cancels against the log, so the gradient stays large for confident mistakes.

One gradient step by hand, from \(\beta = 0\). Every student gets \(p = 0.5\), so the misses \(p - y\) are \((0.5, 0.5, -0.5, 0.5, -0.5, -0.5)\). The mean gradient \(\frac1n X^\top(p - y)\) is

\[ \begin{aligned} \text{intercept: } &\tfrac16(0.5 + 0.5 - 0.5 + 0.5 - 0.5 - 0.5) = 0 \\ \text{hours: } &\tfrac16(0.5 + 1 - 1.5 + 2 - 2.5 - 3) = \tfrac{-3.5}{6} = -0.583 \end{aligned} \]

In words: the intercept is already right on average (half the students passed, and \(p = 0.5\)), but the misses line up negatively with hours: the model under-predicts the students who studied more. With learning rate 0.1 the step is \(\beta = (0, 0.058)\), and the mean log loss falls from \(\log 2 = 0.693\) to 0.666. With learning rate 1 the step overshoots to \((0, 0.583)\) and the loss rises to 0.856: on raw hours, any rate above \(8/\mu_{\max} = 0.50\) isn't guaranteed to converge (\(\mu_{\max} = 16.0\) is the largest eigenvalue of \(X^\top X/n\), and log loss curves at most a quarter as much as squared error because \(p(1 - p) \le \tfrac14\)).

Convex, but no closed form

Differentiate the gradient once more. Only \(p\) depends on \(\beta\), and \(\partial p_i/\partial\beta = p_i(1 - p_i)x_i\):

\[ \begin{aligned} \nabla^2 J &= X^\top W X, \quad W = \operatorname{diag}\big(p_i(1 - p_i)\big) \\ v^\top X^\top W X v &= \sum_i p_i(1 - p_i)\,(x_i^\top v)^2 \ge 0 \end{aligned} \]

In words: the curvature in any direction is a weighted sum of squares, never negative, so log loss is convex: any point where the gradient is zero is the global minimum. Each row's weight \(p_i(1 - p_i)\) is largest for borderline cases and near zero for rows the model is sure about.

But setting the gradient to zero gives \(X^\top(\sigma(X\beta) - y) = 0\), with \(\beta\) trapped inside the sigmoid: no algebra gets it out. So it's solved iteratively. At the solution the intercept's equation says \(\sum_i (p_i - y_i) = 0\): the average predicted probability equals the observed rate (here 0.5 and 0.5), the logistic version of “residuals sum to zero”.

Newton's method and IRLS, one step by hand

Gradient descent uses only the slope. Newton's method also uses the curvature: at the current point it fits the paraboloid with the same slope and curvature, and jumps to that paraboloid's bottom:

\[ \beta \leftarrow \beta - (X^\top W X)^{-1}X^\top (p - y) \]

In words: divide the slope by the curvature, the matrix version of \(x \leftarrow x - f'/f''\). For squared error the bowl is a paraboloid, so one Newton step from anywhere lands on the normal equations' answer. For log loss the bowl only looks like a paraboloid nearby, so you jump, rebuild, and jump again.

Step 1 by hand. At \(\beta = 0\), every \(W_{ii} = 0.25\), so the curvature is a quarter of \(X^\top X\):

\[ \begin{aligned} X^\top X &= \begin{bmatrix} 6 & 21 \\ 21 & 91 \end{bmatrix}, \quad X^\top W X = \begin{bmatrix} 1.5 & 5.25 \\ 5.25 & 22.75 \end{bmatrix}, \quad X^\top (p - y) = \begin{bmatrix} 0 \\ -3.5 \end{bmatrix} \\ (X^\top W X)^{-1} &= \frac{1}{1.5 \times 22.75 - 5.25^2}\begin{bmatrix} 22.75 & -5.25 \\ -5.25 & 1.5 \end{bmatrix} = \frac{1}{6.5625}\begin{bmatrix} 22.75 & -5.25 \\ -5.25 & 1.5 \end{bmatrix} \\ \beta_1 &= 0 - \frac{1}{6.5625}\begin{bmatrix} 22.75 \times 0 - 5.25 \times (-3.5) \\ -5.25 \times 0 + 1.5 \times (-3.5) \end{bmatrix} = -\begin{bmatrix} 2.8 \\ -0.8 \end{bmatrix} = \begin{bmatrix} -2.8 \\ 0.8 \end{bmatrix} \end{aligned} \]

In words: one jump takes the model from “everyone 50%” to \(-2.8 + 0.8 \times \text{hours}\). A shortcut worth knowing: from \(\beta = 0\), \(W = I/4\), so the first Newton step is exactly 4 times the OLS fit of \(y - 0.5\) on \(X\). That fit is \(-0.7 + 0.2x\) (the linear probability model shifted down by 0.5), and 4 times it is \((-2.8, 0.8)\).

IRLS: each Newton step is a weighted least-squares fit. Rearranging the step gives \(\beta^{\text{new}} = (X^\top W X)^{-1}X^\top W u\) with a working target \(u = X\beta + W^{-1}(y - p)\): regress \(u\) on \(X\) with row weights \(W\). Here \(u\) is the current score plus each miss converted into score units (divided by the sigmoid's slope); at \(\beta = 0\) it's \(\pm 0.5/0.25 = \pm 2\). Because the weights change every step, it's iteratively reweighted least squares, the classic way to fit any GLM.

  • Cost: each step builds a \(k \times k\) curvature (\(O(nk^2)\)) and solves it (\(O(k^3)\)). Great up to a few thousand features; beyond that, L-BFGS (which approximates the curvature from recent gradients, and is sklearn's default) or SGD for huge \(n\).
  • No scaling or learning rate needed: Newton measures the bowl's shape and undoes it.
  • Where it misbehaves: far from the bottom a full step can overshoot, so real solvers shrink the step until the loss falls; under separation \(W \to 0\) and the steps run off (section 07).

Reading a coefficient: odds ratios

One more hour adds 1.214 to the log-odds, whatever the student's other features. Adding to a log multiplies the thing inside it, so the odds are multiplied by \(e^{1.214} = 3.37\): the odds ratio.

\[ \frac{\text{odds}(x_j + 1)}{\text{odds}(x_j)} = \frac{e^{\beta_0 + \beta_j(x_j + 1) + \dots}}{e^{\beta_0 + \beta_j x_j + \dots}} = e^{\beta_j} \]

In words: \(e^{\beta_j}\) above 1 raises the odds, below 1 lowers them, exactly 1 means no effect. It's the same multiplier everywhere; the change in probability isn't:

  • Non-collapsibility: unlike linear regression, leaving out a predictor that affects the outcome shrinks the other log-odds coefficients towards zero even when it's uncorrelated with them, so odds ratios from models with different features aren't comparable.

Standard errors and tests. The covariance of \(\hat\beta\) is the inverse curvature at the optimum, \((X^\top W X)^{-1}\) (the inverse Fisher information; there's no separate \(\sigma^2\), because a coin flip's variance \(p(1 - p)\) is fixed by its mean). For the students the slope's SE is 0.913, so the Wald statistic (estimate ÷ SE, compared with a standard normal) is \(z = 1.214/0.913 = 1.33\) (\(p = 0.18\)), and the 95% interval for the odds ratio is \(e^{1.214 \pm 1.96 \times 0.913} = [0.56, 20.1]\): six students can't establish much. The likelihood-ratio test compares deviances (\(-2\) log-likelihood): 8.32 for the intercept-only model, 4.96 for the fit, a drop of 3.36 on 1 degree of freedom, \(p = 0.067\). In small samples or near separation the two disagree, and the likelihood-ratio test is the more trustworthy. The same deviances give McFadden's pseudo-\(R^2\), \(1 - 4.96/8.32 = 0.40\): the share of the intercept-only model's deviance the features remove (not comparable with an OLS \(R^2\)).

The decision boundary is linear

Predict “pass” when \(p \ge t\). The sigmoid only ever rises, so that's the same as \(x^\top\beta \ge \operatorname{logit}(t)\): a straight line in two features, a flat plane in three, a hyperplane in general. For the students, \(t = 0.5\) means \(z \ge 0\), so hours \(\ge 4.249/1.214 = 3.5\). Lowering the threshold to 0.2 (\(\operatorname{logit} 0.2 = -1.386\)) moves the boundary to \((4.249 - 1.386)/1.214 = 2.36\) hours: the threshold shifts the plane, it never bends it. Curved boundaries need curved features (squares, interactions, splines) or a different model; how to pick \(t\) from costs is in evaluation.

Say it in an interview: “Logistic regression models the log-odds as \(x^\top\beta\) and maps them to a probability with the sigmoid. Training minimizes log loss, the Bernoulli negative log-likelihood; its gradient is \(X^\top(p - y)\), the same shape as linear regression's, and its Hessian \(X^\top W X\) with \(W = p(1 - p)\) is positive semidefinite, so it's convex. There's no closed form, so I'd use Newton/IRLS, which converges in a handful of steps, or L-BFGS or SGD at scale. A coefficient is a log odds ratio: \(e^{\beta}\) multiplies the odds per unit, and the probability moves by at most \(\beta/4\). The boundary \(x^\top\beta = \operatorname{logit}(t)\) is a hyperplane.”

07Logistic regression in practice

What logistic regression assumes

  • Log-odds linear in the features you include. Check by binning a feature (say into deciles), computing each bin's observed log-odds \(\log\frac{r}{1 - r}\), and plotting against the bin's average: a curve calls for a spline, a log or bins.
  • Independent rows. Many rows per customer make the standard errors too small, as in OLS: cluster them.
  • No perfect collinearity and no separation (below), or the coefficients aren't defined.
  • Enough events. A common rule of thumb is 10–20 cases of the rarer class per coefficient for stable unpenalized estimates; 1% positives in 1,000 rows is only 10 events. With fewer, regularize.
  • Not needed: normal errors or constant variance. There's no additive noise term; a coin flip's spread \(p(1 - p)\) is fixed by its mean.

Perfect separation: weights run to infinity

Swap two labels so the students are 0, 0, 0, 1, 1, 1: everyone below 3.5 hours failed and everyone above passed. Now any line with its boundary between 3 and 4 hours classifies every student correctly. Take one such \(\beta\) and double it: every \(p_i\) moves closer to its \(y_i\), so the loss drops. Double again, it drops again, forever. The bowl has no bottom in that direction, so no finite maximum-likelihood estimate exists. Gradient descent (rate 1) just keeps walking:

  • Symptoms: huge coefficients and huge standard errors, convergence warnings, training loss near zero, predicted probabilities of exactly 0 or 1. Near separation, Newton's \(W = p(1 - p)\) goes to zero for every row, the curvature matrix becomes nearly singular and the steps run off.
  • Causes: a leaked feature (something filled in only after the outcome, like “sent to collections”): check this first. Quasi-complete separation: one rare category whose few rows all have the same label sends just its coefficient to ±∞. Many features relative to rows, where some separating hyperplane almost always exists.
  • Why a penalty fixes it: the log loss can fall by at most its current value (it's never below zero), while \(\frac\lambda2\lVert\beta\rVert^2\) grows without limit, so the penalized loss climbs again far out and has a finite, unique minimum (the Hessian becomes \(X^\top W X + \lambda I\), strictly positive). With sklearn's L2 penalty: \(C = 1\) gives \(-3.92 + 1.12x\), \(C = 10\) gives \(-9.36 + 2.67x\), \(C = 100\) gives \(-19.8 + 5.65x\), all with the boundary at 3.5. The weaker the penalty, the bigger (and less meaningful) the weights.
  • Other fixes: remove the leak; merge the rare category; Firth's penalized likelihood (a small penalty designed to remove small-sample bias, always finite); exact logistic regression for tiny data.

Trap

“Separation means a great model, ship it.” Perfect training separation in a real problem is almost always leakage or a tiny sample. Even when it's genuine, the unpenalized coefficients are arbitrary (any large enough scaling fits) and the probabilities are overconfident. Small samples are mildly affected even without full separation: maximum-likelihood logistic coefficients are biased away from zero by an amount of order \(1/n\), which is the first-order bias Firth's correction removes.

Class imbalance and the intercept

With 1% positives, a common move is to train on a balanced sample: keep every positive and only a fraction \(q\) of the negatives. What does that do to the model? By Bayes' rule, among the rows you kept, the odds of a positive at any \(x\) are the true odds times \(P(\text{keep} \mid 1)/P(\text{keep} \mid 0) = 1/q\):

\[ \begin{aligned} \text{odds}_{\text{sample}}(x) &= \text{odds}_{\text{true}}(x) \cdot \frac{1}{q} \\ \operatorname{logit} p_{\text{sample}}(x) &= x^\top\beta + \log\frac1q \\ \operatorname{logit} p_{\text{true}}(x) &= \operatorname{logit} p_{\text{sample}}(x) + \log q \end{aligned} \]

In words: undersampling adds the same constant, \(\log(1/q)\), to every log-odds. For a correctly specified model only the intercept moves; the slopes are unchanged. Undo it by adding \(\log q\) (a negative number) back to the score: the prior correction. Oversampling positives \(s\) times, or weighting them \(s\) times more, is the same with \(q = 1/s\).

Simulated: 200,000 rows with a 1.6% base rate, negatives kept with \(q = 0.05\). The undersampled fit has intercept −1.594 against −4.595 on all the data, a shift of 3.001; \(\log(1/0.05) = 2.996\). The slope barely moves (0.982 vs 0.991). Averaged over all 200,000 rows its predictions are 0.207 (on its own training subsample they average 0.244, that subsample's positive rate, as the intercept guarantees); after adding \(\log q\) the full-data average is 0.0158, against the true rate 0.0159.

By hand: base rate 1%, balanced to 50/50 by keeping 1 negative in 99 (\(q = 1/99\)). A balanced-model score of 0.5 has odds 1, true odds \(1/99\), true probability 1%. A score of 0.9: odds 9, true odds \(9/99\), probability 8.3%. Even 0.99 is only 50% in reality.

  • The same odds rescaling handles a deployment shift in the base rate, and is part of recalibration in general (evaluation).
  • Rankings and AUC don't change with an intercept shift, so the correction matters only when the probabilities are used as probabilities (pricing, expected cost, thresholds).
  • Often the simplest answer: train on the natural distribution, keep the probabilities honest, and handle imbalance with the threshold, chosen from the costs of each error (project lifecycle). Resampling methods themselves are in data preparation.
  • With a misspecified or regularized model the slopes move too, so recalibrate on untouched validation data rather than trusting the formula alone.

Calibration, in one line

With an unpenalized intercept, logistic regression's average prediction equals the training base rate, and a well-specified, lightly regularized model is usually close to calibrated; strong regularization, class weights, resampling and distribution shift all break that, and reliability diagrams, Brier score, Platt and isotonic fixes are in evaluation.

More than two classes: softmax

Give each of \(K\) classes its own weight vector, so each row gets \(K\) scores \(z_k = x^\top\beta_k\), and turn them into probabilities that sum to 1 with the softmax, \(p_k = e^{z_k}/\sum_j e^{z_j}\). The loss is cross-entropy (minus the log probability of the true class) and the gradient keeps the same shape, \(X^\top(P - Y)\) with \(Y\) the one-hot labels (loss functions derives it).

  • Only differences between classes are identified: adding the same vector to every \(\beta_k\) changes no probability, so one class is fixed at zero as the reference (or a penalty picks the symmetric solution). With \(K = 2\) the softmax is exactly the sigmoid of \(z_1 - z_0\).
  • Each pair of classes is split by a hyperplane, where their scores tie.
  • One-vs-rest fits \(K\) separate binary models instead; their probabilities don't sum to 1 without renormalizing. Ordered classes (low, medium, high) suit an ordinal (proportional-odds) model, which shares one slope vector across cut-points.

Generalized linear models in one page

Linear and logistic regression are two members of one family. A GLM has three parts: a distribution for \(y\) with mean \(\mu\), a linear score \(\eta = x^\top\beta\), and a link \(g\) with \(g(\mu) = \eta\). Choosing the distribution really means choosing how the variance grows with the mean. Each family has a canonical link, the one that makes the score \(\eta\) the distribution's natural parameter (the logit for Bernoulli, the log for Poisson); the family-to-loss mapping is in loss functions, and what this note adds is how to read and fit them.

Say it in an interview: “If some hyperplane separates the classes, scaling the weights up always lowers log loss, so there's no finite MLE: huge coefficients and SEs, a loss near zero. I'd check for leakage first, then add an L2 penalty, which makes the minimum finite, or use Firth. If I undersample negatives at rate \(q\), only the intercept shifts, by \(\log(1/q)\), so I add \(\log q\) back to the logit to recover true probabilities. Softmax extends it to \(K\) classes, and all of these are GLMs fitted by IRLS.”

08Linear models in practice

Scaling and categorical features

  • Scaling changes nothing for unpenalized OLS or logistic regression solved exactly (coefficients rescale, predictions don't move). It matters for penalties (section 04), for gradient descent's speed (section 01), and for comparing coefficient sizes. Which scaler, and fitting it on training rows only: data preparation.
  • Categories become one-hot columns. Drop one level for an unpenalized model you'll interpret (each coefficient is then a difference from that reference level); keep all levels under a penalty. High-cardinality categories need target encoding or hashing, with their leakage traps: encodings.
  • Skewed positive features (income, counts) often work better logged: the model then says “each doubling of income adds \(\beta\log 2\)”, which is usually closer to how such effects behave.

Polynomial and spline features

A linear model can fit curves if the curve is in the columns.

  • Polynomials add \(x^2, x^3, \dots\). They're global: every coefficient affects the curve everywhere, so fitting a bump on the left swings the right end, and high degrees oscillate wildly near the edges of the data (section 05's degree 12). Centre \(x\) first, keep the degree low (2–3), and never trust them outside the training range.
  • Splines are piecewise polynomials joined smoothly at chosen points, the knots. A cubic spline with knots \(k_1, k_2, \dots\) adds the columns \(x, x^2, x^3\) and one hinge column \((x - k_m)_+^3\) per knot, where \((u)_+ = \max(u, 0)\), so each piece can bend on its own while the curve and its first two derivatives stay continuous. They're local: a bump in one region doesn't move the others. In practice the B-spline basis spans the same curves with better-behaved columns.
  • Natural splines are forced to be straight lines beyond the outer knots, which tames the edges. Put knots at quantiles of \(x\) and choose how many (or the smoothing penalty) by CV. One smooth curve per feature, added up, is a generalized additive model (GAM): still interpretable feature by feature.
  • Interactions are products of columns, \(x_1 x_2\): the effect of one feature depends on another. A linear model only has the ones you add; trees find them by splitting.
  • Binning a feature into ranges fits a step function: easy to read (scorecards do this), but the steps are arbitrary and waste information at the cut-points.

import numpy as np

def add_ones(X):
    return np.column_stack([np.ones(len(X)), X])

years = np.array([[1.], [2], [3], [4], [5]])
salary = np.array([3., 5, 4, 7, 8])

OLS: normal equations, with standard errors

def ols(X, y):
    A = add_ones(X)
    return np.linalg.solve(A.T @ A, A.T @ y)

def ols_with_se(X, y):
    A = add_ones(X)
    n, k = A.shape
    beta = np.linalg.solve(A.T @ A, A.T @ y)
    r = y - A @ beta                    # residuals
    s2 = r @ r / (n - k)                # noise variance
    cov = s2 * np.linalg.inv(A.T @ A)   # need the diagonal
    se = np.sqrt(np.diag(cov))
    return beta, se, beta / se          # and t

# ols(years, salary)         → [1.8, 1.2]
# ols_with_se: se [1.013, 0.306], t [1.78, 3.93]

np.linalg.lstsq(A, y, rcond=None)[0] gives the same answer more stably, and still works when columns are collinear.

OLS by gradient descent

def ols_gd(X, y, lr=0.5, steps=10_000, tol=1e-12):
    mu, sd = X.mean(0), X.std(0)
    Z = (X - mu) / sd                   # standardize
    w, b = np.zeros(Z.shape[1]), 0.0
    for _ in range(steps):
        r = Z @ w + b - y               # misses
        gw, gb = Z.T @ r / len(y), r.mean()
        w -= lr * gw
        b -= lr * gb
        if max(np.abs(gw).max(), abs(gb)) < tol:
            break
    w_raw = w / sd                      # back to raw units
    return np.r_[b - mu @ w_raw, w_raw]

# ols_gd(years, salary)      → [1.8, 1.2]

Ridge, closed form

def ridge(X, y, lam):
    # minimizes ||y - b - Xw||^2 + lam ||w||^2
    mu, ybar = X.mean(0), y.mean()
    Xc, yc = X - mu, y - ybar           # centre: b is free
    I = np.eye(X.shape[1])
    w = np.linalg.solve(Xc.T @ Xc + lam * I, Xc.T @ yc)
    return np.r_[ybar - mu @ w, w]

# ridge(years, salary, 10)   → [3.6, 0.6]
# = sklearn Ridge(alpha=10)

Lasso, by coordinate descent

def soft(z, t):
    return np.sign(z) * np.maximum(np.abs(z) - t, 0)

def lasso_cd(X, y, lam, sweeps=200):
    # minimizes 1/2 ||y - b - Xw||^2 + lam ||w||_1
    mu, ybar = X.mean(0), y.mean()
    Xc = X - mu
    w = np.zeros(X.shape[1])
    r = y - ybar                        # residual at w = 0
    for _ in range(sweeps):
        for j in range(len(w)):
            xj = Xc[:, j]
            r += xj * w[j]              # take j out
            w[j] = soft(xj @ r, lam) / (xj @ xj)
            r -= xj * w[j]              # put it back
    return np.r_[ybar - mu @ w, w]

switches = np.array([4., 1, 3, 0, 2])
X2 = np.column_stack([years[:, 0], switches])
# lasso_cd(X2, salary, 3)  → [3.4, 0.8, -0.2]
# lasso_cd(X2, salary, 6)  → [3.6, 0.6, 0.0]
# = sklearn Lasso(alpha=lam / n)

Logistic regression by gradient descent

def sigmoid(z):
    e = np.exp(-np.abs(z))              # never overflows
    return np.where(z >= 0, 1 / (1 + e), e / (1 + e))

def log_loss(w, A, y):
    z = A @ w
    return np.mean(np.logaddexp(0, z) - y * z)

def logreg_gd(X, y, lr=0.3, steps=20_000, lam=0.0):
    A = add_ones(X)
    w = np.zeros(A.shape[1])
    for _ in range(steps):
        p = sigmoid(A @ w)
        g = A.T @ (p - y) / len(y)      # mean gradient
        g[1:] += lam * w[1:]            # L2, intercept free
        w -= lr * g
    return w

# logreg_gd(hours, passed)          → [-4.249, 1.214]
# log_loss at the fit               → 0.413
# lam=0.1 → [-3.073, 0.878]
#   = sklearn LogisticRegression(C=1/(n*lam))

The stable sigmoid never exponentiates a large positive number, and logaddexp(0, z) computes \(\log(1 + e^z)\) without overflow; clipping probabilities to avoid \(\log 0\) also works but quietly changes the loss near the edges.

Logistic regression by Newton's method

def logreg_newton(X, y, steps=25, tol=1e-10):
    A = add_ones(X)
    w = np.zeros(A.shape[1])
    for _ in range(steps):
        p = sigmoid(A @ w)
        H = A.T @ ((p * (1 - p))[:, None] * A)
        step = np.linalg.solve(H, A.T @ (p - y))
        w -= step
        if np.abs(step).max() < tol:
            break
    p = sigmoid(A @ w)                  # SEs at the optimum
    H = A.T @ ((p * (1 - p))[:, None] * A)
    return w, np.sqrt(np.diag(np.linalg.inv(H)))

# logreg_newton(hours, passed)
# → w [-4.249, 1.214], se [3.388, 0.913]

The same Newton step as IRLS

def logreg_irls(X, y, steps=25):
    A = add_ones(X)
    w = np.zeros(A.shape[1])
    for _ in range(steps):
        z = A @ w
        p = sigmoid(z)
        W = p * (1 - p)
        u = z + (y - p) / W             # working target
        sw = np.sqrt(W)                 # weighted lstsq
        w = np.linalg.lstsq(sw[:, None] * A, sw * u,
                            rcond=None)[0]
    return w

# logreg_irls(hours, passed) → [-4.249, 1.214]

Trap

Mixing up the intercept conventions. Either add a ones column and leave it out of the penalty, or centre \(X\) and \(y\), fit without an intercept and recover it as \(\bar y - \bar x^\top w\). Penalizing the ones column, or adding \(\bar y\) back to a model that already fitted an intercept, shifts every prediction. Also watch shapes: y of shape (n, 1) minus predictions of shape (n,) broadcasts silently into an \(n \times n\) matrix.

Answer out loud first, then open the answer. Each answer stands on its own: the short answer, the mechanism, the why, then the trade-off or the likely follow-up. Questions 2, 8, 18, 24, 25, 26 and 28 are hand drills; do them with a pen.

1Derive the OLS normal equations. What do they mean geometrically?

Minimize \(\lVert y - X\beta \rVert^2\); its gradient \(-2X^\top(y - X\beta)\) is zero when \(X^\top X\hat\beta = X^\top y\). Geometrically, \(\hat y\) is the orthogonal projection of \(y\) onto the column space of \(X\).

  • Steps: expand to \(y^\top y - 2\beta^\top X^\top y + \beta^\top X^\top X\beta\); differentiate (\(\nabla a^\top\beta = a\), \(\nabla \beta^\top A\beta = 2A\beta\) for symmetric \(A\)); set to zero.
  • It's the minimum: the Hessian \(2X^\top X\) is positive semidefinite (\(v^\top X^\top Xv = \lVert Xv \rVert^2\)), so the loss is convex; unique if \(X\) has full column rank.
  • Geometry: \(X^\top(y - X\hat\beta) = 0\) says the residual is perpendicular to every column, so \(\hat y = Hy\) with \(H = X(X^\top X)^{-1}X^\top\), a projection (\(H^2 = H\)).
  • If \(X^\top X\) is singular (duplicate columns, dummy trap, \(p \ge n\)): infinitely many \(\beta\) with the same predictions; lstsq gives the minimum-norm one, ridge makes it unique.

3What does “the residuals are orthogonal to the features” mean, and what follows from it?

At the OLS solution \(X^\top e = 0\): every feature column has zero dot product with the residuals, so no linear pattern in the features is left to explain.

  • Why: if the residuals still lined up with a feature, moving that feature's weight would reduce RSS, so you weren't at the bottom.
  • With an intercept, the ones column gives \(\sum e_i = 0\): the mean prediction equals \(\bar y\) and the line passes through the means.
  • Pythagoras: \(e \perp \hat y - \bar y\), so TSS = ESS + RSS (salaries: 17.2 = 14.4 + 2.8), which keeps in-sample \(R^2\) in \([0, 1]\).
  • Degrees of freedom: \(e\) is confined to \(n - k\) dimensions, hence \(\hat\sigma^2 = \text{RSS}/(n - k)\).
  • Not implied: orthogonality holds by construction in-sample, so it says nothing about whether the model is right; check residual patterns (curves, funnels) instead.

(01)

4Closed form or gradient descent for linear regression? What does each cost, and why not invert \(X^\top X\)?

Solve directly (QR or SVD) up to a few thousand features with data in memory; use gradient descent or SGD for huge, streaming or sparse data, or when there's no closed form.

  • Costs: normal equations \(O(np^2 + p^3)\); QR \(O(np^2)\); SVD the same with a bigger constant; gradient descent \(O(np)\) per step; mini-batch \(O(bp)\).
  • Don't invert: solve is cheaper and more accurate, and forming \(X^\top X\) at all squares the condition number (8.4 → 70 on the salaries), losing digits with correlated features. lstsq works on \(X\) directly and handles rank deficiency.
  • Gradient descent needs scaling: steps grow with the condition number. On raw years, 264 steps at the best fixed rate; centred, 8. The safe learning rate is below \(2/\mu_{\max}\), with \(\mu_{\max}\) the largest eigenvalue of \(X^\top X/n\).
  • No closed form at all: logistic regression, lasso.

(01)

5Why include an intercept, and what does centering the features change?

Without an intercept the line is forced through the origin, which biases the slope; centering doesn't change the fit but makes the intercept the mean of \(y\), decouples it from the slopes, and improves conditioning.

  • No intercept, salaries: slope 1.69 instead of 1.2, residuals summing to 1.64, and \(R^2\) against \(\bar y\) no longer bounded.
  • Centred: \(X^\top X = \operatorname{diag}(5, 10)\); intercept 5.4 = salary at average experience; slope still 1.2; their estimates uncorrelated.
  • Conditioning: eigenvalues of \(X^\top X/n\) go from (11.83, 0.169) to (2, 1), so gradient descent converges far faster.
  • Interactions and polynomials: centring makes main effects mean “at the average of the other feature” and removes most of the collinearity between \(x\) and \(x^2\).
  • Penalties: never penalize the intercept; centre, fit the slopes, recover \(\bar y - \bar x^\top\hat\beta\).

(01)

6List the OLS assumptions. Which are needed for unbiased coefficients and which for valid standard errors?

Linearity, exogeneity, independence, constant variance, normal errors, no perfect collinearity. Unbiasedness needs linearity, exogeneity and full rank; valid classic SEs also need independence and constant variance; normality only for exact small-sample tests and prediction intervals.

  • The one-line reason: \(\hat\beta = \beta + (X^\top X)^{-1}X^\top\varepsilon\). If \(E[\varepsilon \mid X] = 0\) the second term averages to zero (unbiased); its spread is \(\sigma^2(X^\top X)^{-1}\) only if \(\operatorname{Var}(\varepsilon) = \sigma^2 I\).
  • Gauss–Markov: without normality, under the rest, OLS is BLUE, the lowest-variance linear unbiased estimator. Biased estimators like ridge can still have lower total error.
  • Which failure is worst: exogeneity (omitted confounders, reverse causality, measurement error in \(x\)) biases the coefficients, and more data doesn't help. The others mostly break the SEs.
  • For prediction what matters is the right functional form and a stable relationship, checked on held-out data.

(02)

7What happens under heteroscedasticity, how do you detect it, and what do you do?

Coefficients stay unbiased but are no longer the most efficient, and the classic SEs are wrong, so p-values and intervals can't be trusted. Detect with a funnel in residuals vs fitted; fix with robust (HC3) SEs, weighted least squares, or a log target.

  • When it bites: when the noise variance is big where \((x - \bar x)^2\) is big. Simulated with a skewed feature and noise proportional to it: classic SE 0.104 against a true spread of 0.152; “95%” intervals covered the truth 82% of the time; HC3 gave 0.154 and 94%. With a uniform feature the same noise pattern barely mattered.
  • Sandwich: \((X^\top X)^{-1}\big(\sum_i e_i^2 x_ix_i^\top\big)(X^\top X)^{-1}\); HC3 divides each \(e_i^2\) by \((1 - h_{ii})^2\).
  • WLS weights rows by \(1/\sigma_i^2\) and recovers efficiency (slope spread 0.104 → 0.053 in the uniform simulation), if you know the variance pattern.
  • Log target when the noise is multiplicative; it also changes what coefficients mean (percent effects).
  • Formal test: Breusch–Pagan, though the plot usually says enough.

(02)

8Your rows are orders, with many orders per customer. What goes wrong in the regression output, and how do you fix it?

Errors within a customer are correlated, so the rows carry less independent information than their count suggests: coefficients are fine, but the default SEs are too small. Use cluster-robust SEs by customer (or a mixed model).

  • Size of the problem: for a feature constant within clusters of size \(m\), the variance is inflated by about \(1 + (m - 1)\rho\). Simulated with 50 cities of 20 users and \(\rho = 0.2\): naive SE 0.037 against a true 0.080 (\(\sqrt{4.8} = 2.2\) times too small), 63% coverage; clustered SE 0.077, 93%.
  • Drill: paste every row of a dataset in twice. Coefficients unchanged; SEs shrink by about \(1/\sqrt 2\) (salaries: 0.306 → 0.187, \(p\) 0.029 → 0.0002). Nothing new was learned: the formula just assumed independence. Clustered rows are a milder version.
  • How clustering works: sum \(x_ie_i\) within each cluster before squaring, so correlated errors add up instead of cancelling.
  • Cluster at the right level: where errors correlate or treatment was assigned; need enough clusters (a few dozen+), or use a wild cluster bootstrap.
  • Time series: HAC (Newey–West) SEs. For model validation: grouped CV folds, so one customer isn't in both train and validation.

(02)

9How do you read residual plots, and how do you find a point that's distorting the fit?

Residuals vs fitted should be a shapeless band: a curve means missed nonlinearity, a funnel non-constant variance. A Q–Q plot checks the shape of the noise. Leverage and Cook's distance find influential rows.

  • Q–Q: an S (both ends away) means heavy tails, so consider Huber; one end away means skew, so transform \(y\) or use a GLM.
  • Residuals vs time or group: runs or offsets mean dependent rows (Durbin–Watson far from 2).
  • Leverage \(h_{ii}\) (the hat matrix diagonal) flags unusual \(x\); above about \(2k/n\) is worth a look. On the salaries the end points have 0.6 and the middle 0.2.
  • Influence = leverage × a big residual. Cook's distance measures how far all predictions move if the row is dropped; studentized residuals \(e_i/(\hat\sigma\sqrt{1 - h_{ii}})\) undo the fact that high-leverage points hide their own residuals.
  • What to do: inspect the row. Fix data errors; for real extremes prefer a robust loss to deleting.

(02)

10Where does a coefficient's standard error come from? What makes it small, and why divide by \(n - k\)?

\(\operatorname{Var}(\hat\beta) = \sigma^2(X^\top X)^{-1}\), estimated with \(\hat\sigma^2 = \text{RSS}/(n - k)\); the SE is the square root of the diagonal.

  • Derivation: \(\hat\beta - \beta = (X^\top X)^{-1}X^\top\varepsilon\), and \(\operatorname{Var}(A\varepsilon) = A(\sigma^2 I)A^\top\).
  • Salaries: \(\hat\sigma^2 = 2.8/3 = 0.933\); \(\text{SE}(\hat\beta_1) = \sqrt{0.933 \times 5/50} = 0.306\). One feature: \(\sigma^2/S_{xx}\).
  • Small when: little noise, a lot of spread in \(x\), many rows (SE \(\propto 1/\sqrt n\)), little collinearity (variance × VIF).
  • \(n - k\): the fit used \(k\) parameters to bend towards the data, so residuals are smaller than the true errors; they live in \(n - k\) dimensions. RSS\(/n\) (the MLE, 0.56 here) is biased low.
  • Logistic regression: the analogue is \((X^\top WX)^{-1}\), the inverse Fisher information, with no separate \(\sigma^2\).

(03)

11How do you test a coefficient, test several at once, and what's the difference between a confidence and a prediction interval?

\(t = \hat\beta_j/\text{SE}\) on \(n - k\) degrees of freedom; the F-test compares RSS with and without a group of coefficients; a CI is for the mean response, a PI for one new observation and always wider.

  • Salaries: \(t = 3.93\), \(p = 0.029\), 95% CI \(1.2 \pm 3.182 \times 0.306 = [0.23, 2.17]\). The interval excludes 0 exactly when the test rejects.
  • F: \(\frac{(\text{RSS}_r - \text{RSS}_f)/q}{\text{RSS}_f/(n - k)}\); for the slope \((17.2 - 2.8)/(2.8/3) = 15.43 = t^2\). Use it for all dummies of a category, a feature and its square, or collinear twins whose individual tests are both non-significant.
  • CI vs PI at \(x_0\): variance \(\sigma^2x_0^\top(X^\top X)^{-1}x_0\) vs \(\sigma^2(1 + x_0^\top(X^\top X)^{-1}x_0)\). At 3 years: ±1.37 vs ±3.37; at 6 years (extrapolating): ±3.22 vs ±4.46. The PI never shrinks below the noise, and needs normal noise to be right even for huge \(n\).
  • Big data: everything is significant; read effect sizes and intervals.

(03, 03)

12What are R² and adjusted R²? Can R² be negative? Does a high R² mean a good model?

\(R^2 = 1 - \text{RSS}/\text{TSS}\), the share of variance explained relative to predicting the mean; adjusted \(R^2\) penalizes features. On test data \(R^2\) can be negative; a high \(R^2\) doesn't mean the model is right.

  • Salaries: \(R^2 = 1 - 2.8/17.2 = 0.837\); adjusted \(1 - 0.163 \times 4/3 = 0.783\).
  • Training \(R^2\) never decreases when you add a feature, even noise; adjusted \(R^2\) rises only if the new feature's \(\lvert t \rvert \gt 1\). Compare models on held-out error instead.
  • Negative: on test data (worse than a constant at the test set's mean), or in-sample without an intercept (worse than \(\bar y\)).
  • Misleading both ways: a line through a curve can score 0.9 with patterned residuals; noisy human-behaviour targets have low \(R^2\) but real, precisely estimated effects.
  • In-sample with an intercept, \(R^2 = \operatorname{corr}(y, \hat y)^2\).

(03)

13Interpret a coefficient in a log-level, level-log and log-log model, a dummy, and an interaction.

Always “per unit of \(x_j\), holding the other features fixed”; logs turn units into percentages.

  • \(\log y \sim x\): +1 in \(x\) multiplies \(y\) by \(e^\beta\): \(\beta = 0.05\) is +5.13%, \(\beta = 0.2\) is +22.1% (not 20%).
  • \(y \sim \log x\): +1% in \(x\) adds about \(\beta/100\); +10% adds \(\beta\log 1.1\) (0.48 for \(\beta = 5\)).
  • \(\log y \sim \log x\): an elasticity: +1% in \(x\) → about \(+\beta\%\) in \(y\); for \(\beta = 0.8\), +10% → +7.9%.
  • Dummy: the difference from the dropped reference level, everything else equal.
  • Interaction \(\beta_1x_1 + \beta_{12}x_1x_2\): the effect of \(x_1\) is \(\beta_1 + \beta_{12}x_2\), so \(\beta_1\) alone is the effect at \(x_2 = 0\) (or at its mean if centred).
  • Back-transforming a log prediction gives the median; multiply by \(e^{\hat\sigma^2/2}\) or the smearing factor for the mean.

(03)

14What does multicollinearity do, and what doesn't it do?

It inflates the variance of the affected coefficients by the VIF, \(1/(1 - R_j^2)\), so they become unstable, can flip sign and look insignificant; predictions where the correlation holds, and joint tests, are fine.

  • Mechanism: only the part of \(x_j\) the other features can't predict identifies \(\beta_j\); the loss bowl is nearly flat along “more on one, less on the other”.
  • Worked: experience recorded twice (correlation 0.998): coefficients 2.83 and −1.67 with SEs about 6, against 1.2 (SE 0.31) alone. VIF 268, \(\sqrt{268} = 16\)× wider. Over 5,000 redraws each coefficient's spread is about 5.2 and the first is negative about 40% of the time, but their sum's spread is 0.33.
  • Rules of thumb: VIF above 5 worth a look, above 10 serious (SE 3.2× wider).
  • Fixes: nothing (if you only predict and the pattern holds), drop or combine the features, ridge, PCA, or more varied data.

(03; detection in data preparation)

15Give the omitted-variable bias formula. A coefficient changed sign when you added a feature: why?

Leaving out \(x_2\) gives \(E[\tilde\beta_1] = \beta_1 + \beta_2\delta\), with \(\delta\) the slope of \(x_2\) on \(x_1\). The sign flip happens because the two models answer different questions.

  • Derivation: write \(x_2 = \delta_0 + \delta x_1 + u\) and substitute; the short model's slope absorbs \(\beta_2\delta\).
  • Sign: sign(\(\beta_2\)) × sign(corr(\(x_1, x_2\))). No bias if \(\beta_2 = 0\) or \(\delta = 0\). More data doesn't reduce it.
  • Worked: wage on education and ability: 0.873 per year with ability in; ability on education \(\delta = 0.341\); ability's effect 4.29; short model 2.336 = \(0.873 + 4.29 \times 0.341\), more than double.
  • Sign flips: without the new feature, the coefficient carried the new feature's effect “as it usually comes along”; with it, it's the effect at a fixed level of the new feature. Strong collinearity also makes signs unstable.

(03)

16When is a regression coefficient a causal effect?

Only when, given the included features, nothing else that drives \(y\) moves with \(x_j\) (exogeneity). Otherwise it's a conditional association.

  • Broken by: omitted confounders; reverse causality (\(y\) drives \(x\)); selection on the outcome; bad controls (adjusting for a mediator removes part of the effect, for a collider creates a fake one); measurement error in \(x\) (attenuation towards zero).
  • Fixes are design: randomization (A/B tests), quasi-experiments (difference-in-differences, regression discontinuity, matching), instrumental variables, fixed effects for time-invariant confounders.
  • Prediction doesn't need causality: a confounded feature still predicts while the confounding pattern holds. It does matter the moment you act on the feature (raise a price, change a policy).

(03)

17Explain ridge regression: its closed form, what it does to the eigenvalues, and why it never sets coefficients to zero.

Ridge minimizes \(\lVert y - X\beta \rVert^2 + \lambda\lVert\beta\rVert^2\), giving \((X^\top X + \lambda I)^{-1}X^\top y\): it adds \(\lambda\) to every eigenvalue, so along each principal direction it keeps the fraction \(d_j^2/(d_j^2 + \lambda)\) of the OLS signal, which is never zero.

  • Always invertible: \(v^\top(X^\top X + \lambda I)v = \lVert Xv \rVert^2 + \lambda\lVert v \rVert^2 \gt 0\), so it works with duplicate columns and \(p \gt n\).
  • Where it shrinks: thin directions (small \(d_j^2\), the ones collinearity creates) lose almost everything; well-determined ones barely move. Twins example, \(\lambda = 1\): 95% kept along “both up”, 1.8% along “one up, one down”; coefficients go from (2.83, −1.67) to (0.62, 0.53).
  • One feature: \(S_{xy}/(S_{xx} + \lambda)\): 12/20 = 0.6 at \(\lambda = 10\) on the salaries.
  • MAP view: Gaussian prior \(\mathcal N(0, \tau^2)\) with Gaussian noise gives ridge with \(\lambda = \sigma^2/\tau^2\).
  • Never penalize the intercept; standardize first.

(04)

18Hand drill: one centred feature with \(S_{xy} = 12\), \(S_{xx} = 10\). Ridge and lasso slopes at \(\lambda = 6\)? At what \(\lambda\) does lasso hit zero, and why does it?

Ridge \(12/16 = 0.75\); lasso \((12 - 6)/10 = 0.6\); lasso is exactly zero for \(\lambda \ge 12\). Ridge divides, lasso subtracts and clips.

  • Lasso, 1-D: minimize \(\tfrac12\sum(y - \beta x)^2 + \lambda\lvert\beta\rvert\). For \(\beta \gt 0\) the derivative is \(-(S_{xy} - \beta S_{xx}) + \lambda\), zero at \((S_{xy} - \lambda)/S_{xx}\), valid only while \(S_{xy} \gt \lambda\). Otherwise the minimum sits at the kink: the soft threshold \(S(S_{xy}, \lambda)/S_{xx}\).
  • Why zeros: L1's push towards zero has constant size \(\lambda\); L2's (\(2\lambda\beta\)) fades. A coefficient whose data pull \(\lvert x_j^\top r \rvert\) is at most \(\lambda\) sits at zero.
  • Geometry: the L1 budget is a diamond with corners on the axes; error contours usually touch it first at a corner.
  • Bayes: lasso is the MAP under a Laplace prior (sharp peak at 0). Don't confuse a Laplace prior (gives L1) with Laplace noise (gives absolute-error loss).

(04)

19You have two highly correlated features (or the same feature twice). What do ridge, lasso and elastic net do with them?

Ridge splits the weight evenly; lasso tends to put it all on one, and which one is unstable; elastic net keeps both with similar weights.

  • Why: for a fixed total \(w\), \(a^2 + b^2\) is smallest at \(a = b\), while \(\lvert a \rvert + \lvert b \rvert = \lvert w \rvert\) for every same-sign split, so lasso is indifferent and the solver picks a corner.
  • Exact duplicate of years: lasso (1.1, 0), ridge \(12/(20 + \lambda)\) each (0.57 at \(\lambda = 1\)), elastic net (0.56, 0.56).
  • Bootstrap, twins at correlation 0.99: lasso dropped twin 1 in 24% of resamples, its weight ranging 0 to 1.29, while the twins' sum stayed between 1.61 and 1.99; elastic net and ridge never dropped either.
  • Choose: ridge for many small correlated effects; lasso for sparsity with a few real effects; elastic net for sparsity with correlated groups (and more than \(n\) features).

(04)

20Why standardize before ridge or lasso, and should the intercept be penalized?

The penalty charges coefficient size, which depends on units, so without standardizing the units decide how much each feature is shrunk. The intercept should not be penalized.

  • Example: experience in months instead of years. Ridge at \(\lambda = 10\): 0.6 per year vs 1.19 per year; lasso at \(\lambda = 6\): 0.6 vs 1.15. In months \(S_{xx}\) is 144× bigger, so the same \(\lambda\) barely bites.
  • Plain OLS doesn't care: coefficients rescale, predictions don't change.
  • Fit the scaler on training folds only, inside a pipeline, or the CV score leaks.
  • Intercept: penalizing it pulls every prediction towards zero and makes the fit depend on where \(y\) happens to be centred. Centre and recover \(\bar y - \bar x^\top\hat\beta\); watch for solvers that penalize it (sklearn's liblinear).

(04)

21How do you choose λ? And what do sklearn's alpha and C mean?

K-fold cross-validation over a log-spaced grid, with preprocessing inside the pipeline; take the minimum or the one-standard-error choice. sklearn's knobs use different scalings, and C is an inverse strength.

  • Simulated (3 real + 30 junk features, 100 rows): CV error is a U in \(\alpha\); best 0.178 (MSE 4.10, 3 real + 5 junk kept), one-SE choice 0.316 (4.26, 3 junk); OLS on all 33 scores 6.92, on the true 3, 3.94.
  • Folds: time-ordered for time series, grouped for repeated users; nested CV or a holdout for the final score.
  • Speed: warm starts along the path (glmnet, LassoCV); ridge's leave-one-out shortcut \(e_i/(1 - h_{ii})\) (RidgeCV).
  • Scalings: Ridge sums squared errors (\(\alpha = n\lambda\) if your objective is the mean of ½·squared error plus \((\lambda/2)\lVert\beta\rVert^2\)); Lasso averages with a ½ (\(\alpha = \lambda/n\) for \(\tfrac12\text{RSS} + \lambda\lVert\beta\rVert_1\)); LogisticRegression minimizes \(C\sum\ell_i + \tfrac12\lVert w \rVert^2\), L2 with \(C = 1\) by default, \(C = 1/(n\lambda)\), bigger \(C\) = weaker.

(04)

22Derive the bias–variance decomposition. How do model flexibility, λ and more data move each term? What's double descent?

\(E[(y - \hat f(x))^2] = \sigma^2 + (f - \bar f)^2 + E[(\hat f - \bar f)^2]\): noise + bias² + variance. Flexibility trades bias for variance; λ trades variance for bias; data cuts variance only.

  • Derivation: \(y - \hat f = (y - f) + (f - \bar f) + (\bar f - \hat f)\); square and take expectations; the cross terms vanish because \(E[\varepsilon] = 0\), the test noise is independent of the training set, and \(E[\hat f] = \bar f\). Exact only for squared error.
  • Numbers (sin curve, 15 points): degree 1: bias² 0.49, variance 0.01; degree 5: 0.004 and 0.032, the best total 0.126; degree 12: 0.001 and 0.48. Ridge \(\lambda = 0.01\) on degree 12 gets 0.132; 240 points instead of 15 cut its variance to 0.005.
  • Exact for one ridge slope: MSE \(= (\beta^2\lambda^2 + \sigma^2 S_{xx})/(S_{xx} + \lambda)^2\), minimized at \(\lambda^* = \sigma^2/\beta^2\); some \(\lambda \gt 0\) always beats OLS.
  • Double descent: with minimum-norm fits, test error spikes where parameters ≈ rows (60.5 at 15 weights for 15 points), then falls again (0.17 at 21 weights): the smallest-norm interpolant acts as implicit regularization.

(05)

23Why not use linear regression for a binary target? And why log loss rather than squared error for logistic regression?

A straight line leaves \([0, 1]\), forces a constant effect and violates OLS's noise assumptions; squared error through a sigmoid is non-convex and its gradient vanishes for confident mistakes, while log loss is the Bernoulli likelihood, convex, with gradient \(p - y\).

  • Six students: the least-squares line \(-0.2 + 0.2x\) predicts −0.1 at half an hour and 1.4 at 8 hours.
  • Noise: a 0/1 outcome has variance \(p(1 - p)\), heteroscedastic by construction and not normal.
  • Squared error's gradient in the score is \((p - y)p(1 - p)\): near zero exactly when the model is confidently wrong. Log loss's is \(p - y\), full size.
  • Still fine: the linear probability model for quick effect estimates in the middle of the range; squared error on probabilities (the Brier score) for evaluating.

(06; the loss comparison in loss functions)

24Hand drill: derive the logistic gradient, then take one gradient step from zero on hours (1–6) with passed (0, 0, 1, 0, 1, 1).

Per row the loss is \(\log(1 + e^z) - yz\), whose derivative in \(z\) is \(\sigma(z) - y\); the chain rule gives \(\nabla J = X^\top(p - y)\). From zero, the mean gradient is \((0, -0.583)\).

  • At \(\beta = 0\): every \(p = 0.5\); misses \(p - y = (0.5, 0.5, -0.5, 0.5, -0.5, -0.5)\).
  • Intercept entry: mean of the misses, 0 (the base rate is already 0.5).
  • Hours entry: \((0.5 + 1 - 1.5 + 2 - 2.5 - 3)/6 = -3.5/6 = -0.583\).
  • Step with rate 0.1: \(\beta = (0, 0.058)\); mean log loss 0.693 → 0.666. With rate 1 it overshoots to \((0, 0.583)\) and the loss rises to 0.856; on raw hours the guaranteed-safe rate is below \(8/\mu_{\max} = 0.50\).
  • Why it's so clean: the sigmoid's slope \(p(1 - p)\) cancels the log's \(1/(p(1 - p))\).

(06)

25Hand drill: take one Newton step from zero on the same six students. Why does Newton converge so fast, and when wouldn't you use it?

\(\beta \leftarrow \beta - (X^\top WX)^{-1}X^\top(p - y)\); from zero it lands on \((-2.8, 0.8)\), and four steps reach \((-4.249, 1.214)\).

  • At zero: \(W = 0.25I\), so \(X^\top WX = [[1.5, 5.25], [5.25, 22.75]]\), determinant 6.5625; gradient \((0, -3.5)\). Step \(= -\tfrac{1}{6.5625}(5.25 \times 3.5,\ -1.5 \times 3.5) = (-2.8, 0.8)\).
  • Shortcut: from zero, the Newton step is 4 × the OLS fit of \(y - 0.5\), which is \(-0.7 + 0.2x\).
  • Fast: it uses curvature to rescale the step, and near the optimum the error squares each step (gradient 0.0096 → 0.00006 → 0.000000002). No learning rate, no scaling needed.
  • IRLS: each step is a weighted least-squares fit of the working target \(u = z + (y - p)/W\) with weights \(W\).
  • Not when: many features (each step costs \(O(nk^2 + k^3)\); use L-BFGS), huge \(n\) (SGD), or separation (\(W \to 0\), steps run off). Far from the optimum, damp the step.

(06)

26Hand drill: a logistic coefficient is 0.6. Interpret it. If a customer's probability is 0.2, what is it after a one-unit increase?

Each unit multiplies the odds by \(e^{0.6} = 1.82\). From \(p = 0.2\): odds 0.25 → 0.456, so \(p = 0.456/1.456 = 0.31\).

  • Not “+0.6 to the probability” and not “+60%”: it's +0.6 on the log-odds.
  • The probability change depends on where you start: about \(\beta p(1 - p)\). From 0.5 the same unit gives 0.65; no one-unit step can move the probability more than \(\beta/4 = 0.15\), the curve's steepest slope (divide-by-4 rule).
  • Students: \(e^{1.214} = 3.37\) per hour; the probability moves +0.09 at 1 hour, +0.27 across the boundary at 3.5, +0.03 at 6.
  • Odds ratio ≈ risk ratio only for rare outcomes. \(\beta = 0.693\) doubles the odds; \(\beta = -0.5\) cuts them by 39%. Ten units: \(e^{10\beta}\).
  • Uncertainty: exponentiate the CI for \(\beta\): \(e^{\hat\beta \pm 1.96\,\text{SE}}\).

(06)

27Your logistic regression has huge coefficients, huge standard errors and a training loss near zero. What happened and what do you do?

Perfect or quasi-complete separation: some hyperplane splits the classes, so scaling the weights up always lowers the loss and no finite MLE exists. Check for leakage, then regularize.

  • Students relabelled 0, 0, 0, 1, 1, 1: gradient descent's slope grows 1.7 → 4.2 → 8.3 → 12.9 over 100 to 100,000 steps while the loss falls towards 0 and the boundary stays at 3.5; statsmodels reports SEs in the tens of thousands.
  • Causes: a leaked post-outcome feature; a rare category with all-one-label rows; many features per row.
  • Fixes: remove the leak; merge rare categories; L2 (the penalty grows without bound while the loss can't go below zero, so the minimum is finite: \(C = 1\) gives slope 1.12); Firth's correction.
  • Newton's view: \(W = p(1 - p) \to 0\), the Hessian becomes nearly singular, the steps run off.

(07)

28Hand drill: the base rate is 1%, and you trained on a 50/50 sample made by keeping 1 in 99 negatives. The model outputs 0.9. What's the real probability, and why does only the intercept change?

About 8.3%: the odds 9 must be multiplied by \(q = 1/99\), giving 0.091. Undersampling multiplies every row's odds by \(1/q\), which only adds \(\log(1/q)\) to the intercept.

  • Bayes: among kept rows, odds = true odds × \(P(\text{keep} \mid 1)/P(\text{keep} \mid 0) = \) true odds\(/q\), the same factor at every \(x\).
  • Correction: \(\operatorname{logit} p_{\text{true}} = \operatorname{logit} p_{\text{sample}} + \log q\). A score of 0.5 → 1%; 0.99 → 50%.
  • Simulated (base 1.6%, \(q = 0.05\)): intercept shift 3.001 vs \(\log 20 = 2.996\); slope 0.98 vs 0.99; corrected mean prediction 0.0158 vs the true 0.0159.
  • Caveats: exact only for a correctly specified model; otherwise recalibrate on untouched data. AUC is unaffected. Class weights act the same way, with \(s = w_1/w_0\).
  • Often simpler: train on natural data and move the threshold instead.

(07)

29Show that linear and logistic regression are both GLMs. What would you use for counts, and for more than two classes?

A GLM is a distribution for \(y\), a linear score \(\eta = x^\top\beta\), and a link \(g(\mu) = \eta\). Linear regression: Gaussian, identity link. Logistic: Bernoulli, logit link. Counts: Poisson with a log link. \(K\) classes: softmax (multinomial logistic).

  • Variance functions: Gaussian constant, Bernoulli \(\mu(1 - \mu)\), Poisson \(\mu\), Gamma \(\mu^2\). Choosing a GLM means choosing how spread grows with the mean.
  • Fitting: maximum likelihood by IRLS; with the canonical link the gradient is \(X^\top(\mu - y)\) and IRLS is Newton's method. Deviance replaces RSS.
  • Poisson: \(e^\beta\) is a rate ratio (\(\beta = 0.1\) → +10.5%); use \(\log(\text{exposure})\) as an offset; overdispersion → negative binomial.
  • Softmax: one weight vector per class, \(p_k = e^{z_k}/\sum_j e^{z_j}\), gradient \(X^\top(P - Y)\); one class is the reference since only differences are identified; with two classes it's the sigmoid.

(07, 07)

30Write OLS and logistic regression from scratch in NumPy.

OLS: add a ones column and solve the normal equations. Logistic: loop gradient steps \(w \leftarrow w - \eta X^\top(\sigma(Xw) - y)/n\), or Newton steps with \(H = X^\top WX\).

  • OLS: A = np.column_stack([np.ones(n), X]); beta = np.linalg.solve(A.T @ A, A.T @ y) (or lstsq). Salaries → (1.8, 1.2). SEs: s2 = r @ r / (n - k), np.sqrt(np.diag(s2 * inv(A.T @ A))).
  • Logistic GD: p = sigmoid(A @ w); w -= lr * A.T @ (p - y) / n; leave the intercept out of any penalty. Students, rate 0.3 → (−4.249, 1.214) within 5,000 steps.
  • Stability: a sigmoid that never exponentiates a large positive number; loss via np.logaddexp(0, z) - y * z.
  • Newton: H = A.T @ ((p * (1 - p))[:, None] * A); w -= np.linalg.solve(H, A.T @ (p - y)); converges in about 5 steps; inv(H) at the end gives the SEs.
  • Pitfalls: penalizing the intercept, (n, 1) vs (n,) broadcasting, unscaled features with gradient descent, no convergence check.

(09)

31When would you choose a linear or logistic model over gradient-boosted trees?

Small data, smooth additive effects, sparse high-dimensional features, a need for interpretable coefficients or calibrated probabilities, extrapolating a trend, or tight latency; and always as the baseline.

  • Small data / few events: few parameters, low variance; regularization handles the rest.
  • Sparse text or one-hot IDs: L1/L2 linear models are fast, strong and cheap to serve.
  • Interpretation and regulation: each effect is one number with an SE; credit scorecards.
  • Extrapolation: trees predict flat beyond the data; a line continues the trend (with care).
  • Trees win when the signal is in interactions, thresholds and nonlinearity, with mixed types and missing values. If boosting wins by a lot, the linear model's residuals usually show the missing curve or interaction, which splines or products can add.

(08)

32What does logistic regression assume? Which OLS assumptions does it not need?

Log-odds linear in the included features, independent rows, no perfect collinearity or separation, and enough events per coefficient. It doesn't need normal errors or constant variance.

  • Linearity is on the log-odds scale: check by binning a feature and plotting each bin's observed log-odds; fix curves with splines, logs or bins.
  • Independence: repeated rows per customer make SEs too small; cluster them, or use GEE or a mixed-effects model.
  • Events per coefficient: roughly 10–20 of the rarer class per coefficient for stable unpenalized estimates; below that, regularize (small samples also bias coefficients away from zero).
  • No separation: otherwise there's no finite MLE.
  • Not needed: there's no additive noise term, so no normality or homoscedasticity; the Bernoulli variance \(p(1 - p)\) is set by the mean, which is also why there's no separate \(\sigma^2\) in the SEs.

12Cheat sheet

Least squares

\[ \begin{aligned} \hat\beta &= (X^\top X)^{-1}X^\top y, \quad X^\top e = 0 \\ \hat\beta_1 &= S_{xy}/S_{xx}, \quad \hat\beta_0 = \bar y - \hat\beta_1\bar x \\ H &= X(X^\top X)^{-1}X^\top, \quad \textstyle\sum_i h_{ii} = k \\ \beta &\leftarrow \beta - \eta\,\tfrac1n X^\top(X\beta - y) \end{aligned} \]

Salaries: \(1.8 + 1.2x\), residuals (0, 0.8, −1.4, 0.4, 0.2), TSS 17.2 = ESS 14.4 + RSS 2.8. Projection onto the column space; residuals sum to 0 with an intercept. Solve with QR/lstsq, never invert; GD needs scaling (steps ∝ condition number: 260 raw vs 8 centred). Centre: intercept = \(\bar y\), slopes decouple.

Assumptions

Unbiased: linearity, exogeneity (\(E[\varepsilon \mid X] = 0\)), full rank. Valid classic SEs: + independence, constant variance. Exact small-sample tests and PIs: + normality. Gauss–Markov: OLS is BLUE without normality. Omitted confounder → biased; heteroscedasticity → HC3 SEs or WLS; clusters → cluster-robust SEs (design effect \(1 + (m - 1)\rho\)); time series → HAC. Funnel = variance, curve = shape, Q–Q S = heavy tails, leverage × residual = influence.

Inference

\[ \begin{aligned} \operatorname{Var}(\hat\beta) &= \sigma^2(X^\top X)^{-1}, \quad \hat\sigma^2 = \text{RSS}/(n - k) \\ t &= \hat\beta_j/\text{SE}_j \sim t_{n-k} \\ F &= \frac{(\text{RSS}_r - \text{RSS}_f)/q}{\text{RSS}_f/(n - k)} \\ R^2 &= 1 - \text{RSS}/\text{TSS}, \quad \bar R^2 = 1 - (1 - R^2)\tfrac{n - 1}{n - p - 1} \\ \operatorname{Var}(\hat\beta_j) &= \frac{\sigma^2}{\sum_i (x_{ij} - \bar x_j)^2\,(1 - R_j^2)}, \quad \text{VIF}_j = \frac{1}{1 - R_j^2} \\ E[\tilde\beta_1] &= \beta_1 + \beta_2\delta \end{aligned} \]

Salaries: SE 0.306, \(t = 3.93\), \(p = 0.029\), CI [0.23, 2.17], \(F = 15.43 = t^2\), \(R^2 = 0.837\), adjusted 0.783. PI adds \(\sigma^2\) to the CI's variance. Log-level: \(e^\beta - 1\); log-log: elasticity. Collinear twins: SE 0.31 → 6.0, sum stable. Education/ability: 0.873 + 4.29 × 0.341 = 2.336.

Regularization

\[ \begin{aligned} \hat\beta_{\text{ridge}} &= (X^\top X + \lambda I)^{-1}X^\top y, \quad \text{keeps } \tfrac{d_j^2}{d_j^2 + \lambda} \text{ per direction} \\ \hat\beta_{\text{lasso, 1-D}} &= S(S_{xy}, \lambda)/S_{xx}, \quad S(z, \lambda) = \operatorname{sign}(z)\max(\lvert z \rvert - \lambda, 0) \\ \text{elastic net} &: \lambda\big(\alpha\lVert\beta\rVert_1 + \tfrac{1 - \alpha}{2}\lVert\beta\rVert_2^2\big) \end{aligned} \]

Salaries at \(\lambda = 6\): ridge 0.75, lasso 0.6; lasso zero from \(\lambda = 12\). Lasso zero when \(\lvert x_j^\top r \rvert \le \lambda\); coordinate descent = repeated soft thresholds. Ridge shares between twins, lasso picks one, elastic net groups. Standardize first, never penalize the intercept, λ by CV (one-SE rule). MAP: Gaussian prior → ridge with \(\lambda = \sigma^2/\tau^2\); Laplace → lasso. sklearn: Ridge \(\alpha = n\lambda\); Lasso averages with ½; logistic \(C = 1/(n\lambda)\), L2 \(C = 1\) by default.

Bias and variance

\[ \begin{aligned} E[(y - \hat f)^2] &= \sigma^2 + (f - \bar f)^2 + E[(\hat f - \bar f)^2] \\ \text{MSE}_{\text{ridge slope}}(\lambda) &= \frac{\beta^2\lambda^2 + \sigma^2 S_{xx}}{(S_{xx} + \lambda)^2}, \quad \lambda^* = \sigma^2/\beta^2 \end{aligned} \]

Flexibility: bias ↓ variance ↑ (sin curve: degree 1 0.594, degree 5 0.126, degree 12 0.570). λ: bias ↑ variance ↓. Data: variance ↓ only. Double descent: spike at parameters ≈ rows, then down with minimum-norm fits.

Logistic regression

\[ \begin{aligned} \log\tfrac{p}{1 - p} &= x^\top\beta, \quad p = \sigma(z), \quad \sigma' = p(1 - p) \\ J &= \textstyle\sum_i \log(1 + e^{z_i}) - y_iz_i, \quad \nabla J = X^\top(p - y) \\ \nabla^2 J &= X^\top WX, \quad W = \operatorname{diag}(p_i(1 - p_i)) \\ \beta &\leftarrow \beta - (X^\top WX)^{-1}X^\top(p - y) \\ \operatorname{logit} p_{\text{true}} &= \operatorname{logit} p_{\text{sample}} + \log q \end{aligned} \]

Students: Newton from 0 → (−2.8, 0.8) → … → (−4.249, 1.214) in 4 steps; boundary 3.5 h; odds ratio \(e^{1.214} = 3.37\); probability moves ≤ \(\beta/4\). First GD gradient (0, −0.583). Convex, no closed form; mean prediction = base rate. Separation → weights to ∞ → L2 or Firth. Undersampling keeps slopes, shifts intercept by \(\log(1/q)\). Softmax for \(K\) classes; GLMs: Gaussian/identity, Bernoulli/logit, Poisson/log.
